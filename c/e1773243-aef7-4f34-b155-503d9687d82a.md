**核心结论**：效果确实会**质变级提升**，但它和原生可编辑形状不是“替代关系”，而是**分工关系**。全用 Python 会毁掉可编辑性，全用原生形状会卡死物理/数学表现力；最优解是 **“80% 原生形状 + 20% Python 局部渲染引擎”的混合路线**。

#### 1. 底层机制区别（第一性原理）
- **PPT 原生形状 + Morph（平滑切换）**本质上是**线性/仿射插值**：PowerPoint 只能在两页之间把同一个形状的位置、缩放、旋转、颜色做起止点平滑过渡。
  - 它天生擅长**刚体位移、缩放推拉、大画布平移、聚光聚焦**（如《书堆》平推书本、《碰撞》撞击散开、《光合作用》沿类囊体膜平移）。
  - 它**做不到非线性数学实时联动**——比如夹角 $\theta$ 匀速转动时，左侧电场投影按 $E_0\cos\theta$ 伸缩，同时右侧光点沿 $I/I_0=\cos^2\theta$ 曲线实时描点；或 RGB 三波长相量随光程差 $\Delta$ 旋转的同时扫出三条正弦透射率曲线。硬用原生形状硬凑，就会退化成你在 `旋转世界` P14–P19 踩过的坑（6 页 `fade(120ms)` 鬼畜假定格）。
- **Python 渲染（Matplotlib Animation / Manim）**本质上是**由物理方程直接逐帧计算 30–60 fps 画面**：
  - 你给的两个顶级物理标杆——《偏振光干涉_熊鑫》（马吕斯定律投影圆 + $\cos^2\theta$ 曲线、RGB 三波长相量联动）和《3B1B 彩虹灯柱》（Manim 本就是 3Blue1Brown 作者开源的 Python 引擎）——**最震撼的那几段核心画面，底层都是 Python 数值计算渲染的**。

#### 2. 关键维度硬对比

| 维度 | PPT 原生可编辑形状 + `!!` Morph | Python（Matplotlib / Manim）渲染嵌入 |
|---|---|---|
| **视觉与物理上限** | 刚体、流程图、标注、公式极清晰；波动/曲线联动/3D 旋转力不从心 | **天花板级**：精确曲线同步描点、矢量场、波叠加、3D 切片、相空间演化，数学 100% 精确 |
| **后期修改成本** | **极低**：WPS/PPT 打开直接拖位置、改字、换色，10 秒搞定 | **高（最大短板）**：嵌入成 `.mp4` 后 PPT 内**无法编辑画面内任何数字或字号**，哪怕改一个下标都必须改代码重渲染再替换 |
| **文件体积** | 极小（0.2–2 MB） | 较大（每嵌 1 段 1080p 10 秒视频约 +2–8 MB） |
| **WPS/PPT 兼容性风险** | `!!` Morph + `fade` 降级回退非常稳 | **有编码坑**：必须用 FFmpeg 压成标准 `H.264 (yuv420p) + MP4`；用非标编码（如 HEVC/VP9/透明 MOV）极易在 WPS 里黑屏或播不动 |
| **制作与调试耗时** | 快，适合批量出页 | 写脚本 + 调坐标系/配色/帧率耗时较高，不适合普通图文页 |

#### 3. 推荐落地策略（如果后续要写入 Skill）
不要一刀切，按镜头复杂度拆成 **80/20 混合制**：
- **80% 镜头保持纯 PPT 原生可编辑**：封面、问题锚定、公式（`m:oMath`）、刚体 `!!` Morph、大画布平移、局部聚光圈、所有文字与标注全部留在 PPT 原生层——确保日常改字改版零门槛。
- **20% 关键原理高光镜头用 Python 局部出片**：仅在“公式—几何—曲线实时联动”“波的干涉叠加”“3D 视角旋转”这类原生做不到的镜头里，用 Python 生成与 PPT **同底色（如 `#101216`）的局部无边框 `H.264 MP4`（或高精度静态矢量 SVG/PNG 曲线）**嵌在舞台一侧，旁边的标题、公式和文字注释**仍然用 PPT 原生文本框覆盖**，并强制把生成该片段的 `.py` 源码归档在同级 `assets/scripts/` 目录里，确保随时可复现修改。
- 注：本机已有 `numpy`、`PIL` 和 `ffmpeg-win-x86_64-v7.1.exe`，但 `matplotlib` / `manim` 是否已安装目前**未验证**；如果你决定启用混合路线，下一步接入学校模板时我可以顺手核查并补写一条按需子规则。

## 二、核心诊断与底层原理

**一句话核心矛盾**：原 `course-ppt-lab` 本质是一套面向**“静态投影课程汇报”**的规则体系（强页眉+底栏来源+填满整页留白+默认关动画），直接拿它做科普短视频 PPT，会系统性地制造出“把汇报页刷成黑底再凑点动画”的半成品，而不是让观众一眼看懂的**视觉叙事镜头**。

### 1. 决定科普视频“一眼看懂”的 4 个第一性原理（来自 3 部标杆视频逆向拆解）
1. **三段式认知阶梯（现象实证 → 极简模型 → 定量联动）**：
   - 《偏振光干涉》先用 20 秒实拍胶带显色立 4 个问题并后文逐一回扣（`00:18–00:52 → 04:46–05:52`），讲马吕斯定律与波长干涉时让**顶部公式、左侧矢量投影/RGB 相量指针、右侧 $\cos^2\theta$/光谱曲线同帧联动**（`01:08–01:25`, `03:55–04:29`），角落一行微注 `公式模型计算，非实测数据`；
   - 《3B1B 彩虹灯柱》从实拍糖水灯柱直切纯黑极简空间单波，再用发光垂直截面（Slice）切片降维（`03:51`），并用红标 `Don't imagine this` 显式驳斥错误弹丸脑补（`08:57`）。
2. **空间连续性与景别呼吸（绝不 30 页锁死一个机位）**：
   - 《PPT 动画·光合作用》证明纯 PPT 也能拍出电影镜头感：宏观树叶 → 显微叶绿体 → 分子级类囊体膜，再用 Morph 沿长膜平移缩放（`01:37–02:36`），让观众始终知道“局部在整体的哪里”，结尾拉回全景闭环（`05:46`）。
3. **原地注意力导演（克制到极致，不靠翻页刷存在感）**：
   - 同屏多要素时，要么用**原地明暗权重切换（Dim-to-Highlight）**（《偏振光干涉》`05:36–05:52`，未讲项低透明度灰暗，讲到原地提亮），要么用**全景半透明暗罩+局部亮窗（Spotlight）**（《光合作用》`03:00–03:24`, `05:23`），绝不用无意义的 462 次擦除或整页白板蒙版。
4. **画布舞台解放与声画分离**：
   - 三部标杆的镜头画面几乎全部**撤掉常驻汇报页眉/底栏框**，主体模型占 65–85% 舞台，底部留出约 15% 高度作**纯净字幕安全区**，完整因果推演由纯净口播承担。

### 2. 现有历史 PPTX 的真实剖析（保留什么 vs 推翻什么）

- **值得保留的局部有效实践**：
  1. `书堆` 的低画面文字密度（均值 49 字/页）与全量 `!!` 对象命名锁（`!!book-0..3`, `!!table-edge`，10 对 Morph 100% 精准匹配）；
  2. `碰撞` 在 `<p:grpSp>` 组合级使用 `!!` 命名锁（`!!ball-one`, `!!station`），以及惠普尔防护层的**“撞前 Morph → 撞击瞬间硬切生成 21 片 `!!debris` → 撞后 Morph 散开”**三段式拓扑变化写法（已沉淀进 E12）；
  3. `旋转世界`（15 处）与 `碰撞`（11 处）落地了原生可编辑 Office 公式（`m:oMath` + Cambria Math），远胜 `书堆` 的纯文本拼凑。

- **暴露出的 6 大致命短板与前 AI 遗留隐性坑**：
  1. **【规则自相矛盾导致的白屏事故】**：原 `animation-engineering.md` E05 推荐封面/章节用“整页同色不透明矩形 + 退场淡出”，直接导致 `杨立础-新中特.pptx` 在 WPS 渲染和关闭动画时 **P01/P03/P08/P17/P22 整整 5 页变成纯白板**，直接违反 E01。

  4. **【汇报八股枷锁 & 固定单机位疲劳】**：`旋转世界` 与 `碰撞` 每页顶部套页眉+副标题、底部压横线+灰字小结，中间挤简陋火柴人/方块车（`碰撞` P36 论文实拍图还残留无关红叉校准点）；`书堆` 则 35 页锁死同一个机位缩放比。
