## 1. 名词速查
| 词 | 物理图像 |
|---|---|
| **DBR**（分布式布拉格反射镜） | 高、低折射率薄膜交替堆叠，每层光学厚度 λ/4。各界面的反射同相叠加，在一段波长（阻带）内反射率可以超过 99.9%。两块 DBR 面对面放，中间夹一层材料，就成了**微腔**。 |
| **高 Q 值** | Q = λ/Δλ，可以理解成光在腔里来回能撑多少个周期。Q 越高，谱线越窄，光子在腔里活得越久。 |
| **局域场** | 光被限制在很小的空间里（微腔、纳米结构），局部电场强度远高于入射光，光和物质的相互作用就被放大了。 |
| **激射判据** | 实验上一般看四点：① 输出强度随泵浦功率出现**阈值拐点**（S 形曲线）；② 过了阈值**线宽骤然变窄**；③ 有**空间或时间相干性**（干涉条纹、g⁽²⁾ 趋近 1）；④ 偏振选择性增强。只看到"变亮"不够，至少要同时有阈值和线宽变窄。 |
| **超快** | 研究皮秒到飞秒（10⁻¹² ～ 10⁻¹⁵ s）量级的过程，常用泵浦-探测：先用一束脉冲激发样品，再用另一束脉冲延时探测，看载流子或极化激元怎么弛豫。 |
| **激子** | 半导体吸收光后，产生的电子和留下的空穴靠库仑力束缚在一起，形成类氢原子的准粒子。在二维材料里激子束缚得特别牢，室温下也稳定。 |
| **玻色-爱因斯坦凝聚** | 玻色子足够多、足够"冷"时，会大量挤进同一个最低能态，表现出宏观相干性。腔光子和激子强耦合形成的**激子极化激元**质量极轻，所以在比原子气体高得多的温度下就能凝聚。 |
| **哈密顿量 / 非厄米** | 哈密顿量就是描述系统能量的算符，它的本征值是能级。系统有损耗或增益时（腔会漏光、泵浦会补充粒子），哈密顿量不再厄米，本征值变成复数：虚部对应寿命或线宽。这类系统里会出现**奇异点**（两个模式的本征值和本征态同时合并），是现在的热门方向。 |

**它们怎么串起来（根据词汇推测，未验证，建议找师姐确认）：** 用 DBR 做高 Q 微腔，腔里放二维半导体，腔光子和激子强耦合形成极化激元。粒子数足够多时出现凝聚或激射，再用超快光谱看它的动力学，用非厄米模型描述它的损耗和增益。

## 2. NA = 0.7 → θ = 44.4° 这段在算什么
这很可能是**角分辨光谱（傅里叶成像）**：物镜收集不同角度出射的光，每个角度对应一个面内波矢 k∥，于是可以画出腔模的色散曲线。

- 物镜能收到的最大角度：sin θ_max = NA = 0.7，所以 θ_max = arcsin 0.7 ≈ 44.4°。老师算的这一步就是这个。
- 腔光子的色散关系近似为

$$\lambda(\theta) = \lambda_0\sqrt{1-\frac{\sin^2\theta}{n_{\text{eff}}^2}}$$

  角度越大，波长越短（蓝移）。所以 **690 nm 是 θ = 0 处的腔模，631 nm 是物镜能收到的最大角度处的腔模。**
- 反过来求实际 NA：

$$\text{NA}_{\text{实际}} = \sin\theta_{\max} = n_{\text{eff}}\sqrt{1-\left(\frac{631}{690}\right)^2} = 0.405\,n_{\text{eff}}$$
