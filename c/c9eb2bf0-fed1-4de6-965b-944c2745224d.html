2. NA = 0.7 → θ = 44.4° 是怎么回事

$$\sin\theta_{max} = NA = 0.7 \;\Rightarrow\; \theta_{max} = \arcsin 0.7 = 44.4^\circ$$

这是角分辨光谱（傅里叶成像）：物镜后焦面上的每个点对应一个出射角，所以图上的横轴是角度，也就是面内波矢

$$k_\parallel = \frac{2\pi}{\lambda}\sin\theta$$

你看到的 631–690 nm 的图应该就是色散图（波长对角度）。物镜能收集到的最大角度由 NA 决定，色散曲线在图上的截止边缘就对应 44.4°。老师的思路是反过来用：从截止处的波长和 k 读出实际的 sinθ_max，也就是实际 NA，再和标称值 0.7 对照，以此检验光路有没有用满 NA。

3. 消色差光路（接上文）

解法：

  • 消色差双胶合透镜：一片冕牌玻璃正透镜（色散小）加一片火石玻璃负透镜（色散大）。设计条件是

$$\frac{\phi_1}{V_1} + \frac{\phi_2}{V_2} = 0$$

其中 φ 是光焦度，V 是阿贝数（数值越大，色散越小）。满足这个条件，两个波长（通常取 F 线和 C 线）的焦点就会重合。总光焦度 φ₁+φ₂ 不为零，所以透镜仍然能成像。

  • 复消色差（APO）：让三个波长的焦点重合，用于宽带成像。
  • 反射式光路：用离轴抛物面镜等反射元件代替透镜。反射角与波长无关，从原理上就没有色差，代价是不好调。

为什么组里在意：角分辨光谱依靠"后焦面上的位置 ↔ 出射角"这一一一对应关系。如果 631 nm 和 690 nm 的后焦面位置不同，同一角度在不同波长下会落在不同位置，色散图就会被拉歪，反推出的 NA 也就不准。

一条典型的傅里叶成像链路：

样品 → 物镜(NA 0.7) → 后焦面 → 透镜L1 → 透镜L2(把后焦面成像到光谱仪狭缝) → 光谱仪 + CCD

L1 和 L2 都应选消色差双胶合透镜，而且要冕牌那一面朝向平行光，这样球差最小。

4. 莫尔转角：建议的学习顺序

  • 几何：两套周期为 a 的晶格相对转 θ，莫尔周期 $a_M \approx a/(2\sin(\theta/2)) \approx a/\theta$。用 Python 画两套六角点阵叠加，亲眼看看图案（30 分钟就能完成）。
  • 魔角石墨烯：θ ≈ 1.1° 时能带变平，出现超导。这是这个领域的起点，可以读 Cao et al., *Nature* 556, 43 (2018)。
  • 莫尔激子：二维半导体（如 WSe₂/WS₂）扭转后，激子被困在莫尔势阱里。这一步和你们组最相关。
  • 莫尔光子学：把"扭转"思想用到光子晶体上（twisted photonic lattices），从而控制光的局域和色散。

一、高频词的统一因果链（精简映射）

1. 光学腔的“牢笼”与“放大器”

  • DBR（Distributed Bragg Reflector，分布式布拉格反射镜）：用高、低折射率介质交替镀膜，每层光学厚度严格等于目标中心波长的 $\lambda/(4n)$，靠多界面反射相干相长形成高反带（Stopband）。两片 DBR 面对面夹一个腔层，就构成高反射率平面微腔（Fabry-Pérot cavity）。实验盲区：DBR 只在有限带宽内高反，带边反射率会陡降，短波或大角度处容易出现截断。
  • 高 Q 值（Quality Factor）：$Q = \dfrac{\omega_0}{\Delta\omega} = \omega_0 \tau_c$。物理上衡量光子在腔里被锁住的平均寿命 $\tau_c$ 有多长；光谱上直接表现为腔模线宽 $\Delta\lambda$ 极窄，光子能量损耗极低，才容易达到激光或凝聚阈值。
  • 局域场（Local Field）：把光子能量压缩到极小的有效模式体积 $V_{\text{eff}}$ 内。电场能量密度暴增后，既能通过 Purcell 效应加速自发辐射，也能把光与物质的耦合强度 $g \propto 1/\sqrt{V_{\text{eff}}}$ 拉高，是进强耦合区和降阈值激光的关键。

2. 激发源、激子 BEC、激光判据与非厄米模型

  • 超快（Ultrafast）：指脉宽在飞秒（fs, $10^{-15}\text{ s}$）到皮秒（ps, $10^{-12}\text{ s}$）量级的脉冲激光。实验上用它主要图两件事：① 极短时间内集中能量，峰值功率极高而平均热负载低，能在不烧毁样品的前提下打过阈值；② 配合泵浦-探测（pump-probe）或条纹相机做时间分辨测量，直接看 ps 尺度的激子形成、弛豫与退相干动力学。
  • 激发激子（Exciton）与玻色-爱因斯坦凝聚（BEC）：半导体吸光后，电子跃迁到导带并与价带留下的空穴靠库仑力束缚成电中性的准粒子，就是激子（整数自旋，属于玻色子）。激子本身较重，单独做 BEC 往往需要极低温度；但如果把它放进高 Q 微腔并与腔光子发生强耦合，会杂化成新准粒子激子极化激元（Exciton-Polariton）。它的有效质量极轻（比电子轻几个数量级），因此在液氦甚至室温下就能发生宏观占据基态（$k_\parallel = 0$）的 BEC——实验中常称极化激元激光（Polariton Lasing，无需粒子数反转），这与传统半导体的弱耦合光子激光（Photon Lasing，需粒子数反转）有本质区别。
  • 判断激光生成的条件（组会最易踩雷点）：“出现一个单峰”绝对不等于出了激光！ 即使只是普通自发辐射被高 Q 腔模过滤，光谱上也会出现一个尖锐单峰。实验室判定出光（无论是光子激光还是极化激元 BEC）必须交叉核查四件事：
  • 输入-输出阈值拐点：出射光强随泵浦功率呈非线性陡增（双对数坐标下的“S 型曲线”）；
  • 线宽突变变窄：跨过阈值时半高全宽（FWHM）急剧压缩；
  • 相干性建立：空间干涉可见度（$g^{(1)}$）突增，或二阶光子关联 $g^{(2)}(0) \to 1$；
  • 峰位与动量演化：极化激元 BEC 会在 $k_\parallel=0$ 处宏观集聚并随密度发生持续蓝移；若功率继续加大导致激子离解、蓝移直接跳回裸腔模且阈值再拐一次，那是退化成了第二阈值的传统光子激光。
  • 哈密顿量（$H$）与非厄米哈密顿量（Non-Hermitian $H$）：
  • 教材里的封闭无损系统满足厄米性 $H^\dagger = H$，解出的本征能量全是实数，总能量守恒。
  • 但你们的微腔和激子体系必然是开放系统：一方面有外界超快泵浦注入增益（等效写成虚部 $+i\gamma_{\text{gain}}$），另一方面光子从 DBR 漏出供你探测、激子也会非辐射复合带来损耗（等效写成虚部 $-i\gamma_{\text{loss}}$）。把这种“双向耦合 + 各自的增益/损耗虚部”写进矩阵后，$H^\dagger \neq H$，就是非厄米哈密顿量。它的本征值变成复数：实部决定共振波长/能级劈裂，虚部正负决定模式是衰减还是起振；当参数调到实部与虚部同时简并时，还会出现奇异点（Exceptional Point, EP），用来研究拓扑激光或超灵敏传感。

二、重点拆解：631–690 nm、$\text{NA}=0.7$ 反推实际 NA 与“消色差光路”

前提声明（未验证项）：因为我没看到原图，所以以下先以最常见的“平面微腔角分辨色散（或从正入射到最大角度的单支腔模范围）”来推演因果链，并在最后指出如果图不是角分辨谱时会发生什么偏差，这需要你回组核实原图坐标轴。

1. 先验算师姐的数字，再看导师为什么反驳

  • $\theta = 44.4^\circ$ 怎么算的：物镜在空气（$n=1$）中使用时，数值孔径定义 $\text{NA} = n\sin\theta_{\max}$。代入 $\text{NA}=0.7$，精确解得：

$$\theta_{\max} = \arcsin(0.7) = 44.4270^\circ \approx 44.4^\circ$$

  • 师姐和导师的核心分歧在哪：
  • 师姐大概率是直接读取了物镜筒壁上刻的标称 $\text{NA} = 0.7$，认为物镜既然能收集 $\pm 44.4^\circ$ 锥角内的光，那么图上覆盖的范围就对应 $0^\circ \to 44.4^\circ$，“所以是对的”。
  • 但导师抓住了实验光学的铁律：物镜的标称 NA $\neq$ 整套光路实际传到光谱仪的有效 $\text{NA}_{\text{actual}}$！ 只要物镜后面的中继透镜口径不够、反射镜或狭缝边缘切掉了大角度光线（渐晕/Vignetting），或者光路存在严重色差导致短波端虚焦溢光，最终能进光谱仪的最大发射角 $\theta_{\text{actual}}$ 就会小于 $44.4^\circ$。
  • 如何从波长反推“实际 NA”？（以平面腔模为例）：
  • 对于有效折射率为 $n_{\text{eff}}$ 的平面 Fabry-Pérot 微腔，斜入射时面内波矢守恒，腔内纵模共振波长随空气外发射角 $\theta$ 发生蓝移：

$$\lambda(\theta) = \lambda_0 \sqrt{1 - \left(\frac{\sin\theta}{n_{\text{eff}}}\right)^2}$$

  • 把你听到的两个数字 $\lambda_0 = 690\text{ nm}$（假设对应 $\theta=0^\circ$ 正入射底端）和 $\lambda_{\min} = 631\text{ nm}$（假设对应最大采集角边缘）代入验算：

$$\sqrt{1 - \left(\frac{631}{690}\right)^2} = 0.40460$$

  • 若按师姐的 $\sin\theta_{\max}=0.7$，可倒算出腔的等效折射率需为 $n_{\text{eff}} = 0.7 / 0.40460 = 1.7301$（这在高分子/钙钛矿/氧化物混合微腔中属于合理量级）。反过来，如果材料/腔结构的 $n_{\text{eff}}$ 已知，导师就可以通过光谱最蓝端的截止波长 $\lambda_{\min}$ 直接求解系统实际收集到的 NA：

$$\text{NA}_{\text{actual}} = \sin\theta_{\text{actual}} = n_{\text{eff}} \sqrt{1 - \left(\frac{\lambda_{\min}}{\lambda_0}\right)^2}$$

  • 这一步极易踩的三个失效边界（别盲套公式！）：
  • 欠定陷阱：如果 $n_{\text{eff}}$ 自身也未知，只凭 631 nm 和 690 nm 两个端点数，方程是欠定的（无法同时解出 $n_{\text{eff}}$ 和 $\text{NA}_{\text{actual}}$），必须整条 $\lambda(\theta)$ 抛物线做双参数拟合或已知腔结构；
  • 强耦合偏离：如果样本处于激子强耦合区，测到的是下极化激元支（LPB）而非纯光子腔模，大角度处色散会被激子能级“压平”（反交叉），硬套纯腔模公式反推 $\text{NA}_{\text{actual}}$ 会产生系统误差；
  • 非色散截断：大角度（接近 $44.4^\circ$）下还会出现 TE/TM 偏振劈裂，且 631 nm 也可能是 DBR 高反带边缘反射率掉光造成的截断，而不是孔径角截断。

2. 为什么紧接着必须讲“消色差的光路”？

你从 631 nm 到 690 nm 光信号本身就跨了近 $60\text{ nm}$；如果再加上短波激发激光（如 400 nm 或 532 nm，需核实），整条光路跨越上百纳米。回顾你第 1 次笔记学的高斯公式 $\dfrac{1}{u}+\dfrac{1}{v}=\dfrac{1}{f}$：普通单透镜（如 N-BK7 平凸镜）的玻璃折射率随波长变化（$n_{\text{蓝}} > n_{\text{红}}$），导致短波焦距更短、长波焦距更长，即 $f(631\text{ nm}) < f(690\text{ nm})$。

在这类角分辨/微腔光路里，不消色差会直接引发两处致命故障：

  • 破坏后焦面（BFP，$k$ 空间）的 4f 成像与实际 NA：
  • 实验室测角分辨色散，通常用一套 4f 中继透镜把物镜的后焦面（Back Focal Plane, BFP）成像到光谱仪狭缝上。在后焦面上，离光轴半径满足阿贝正弦条件 $r = f_{\text{obj}}\sin\theta$（不同半径直接代表不同出射角/动量）。
  • 若中继透镜不消色差，631 nm 的后焦面像会落在狭缝前方，690 nm 的像落在狭缝后方（轴向色差），导致你只能对准其中某个波长聚焦，另一端在狭缝上发虚——不仅角度分辨率变糊，而且高角度光线经过不同焦距的放大率偏移与狭缝/镜框遮挡后，不同波长对应到的实际有效 NA 都不一样！
  • 激发与收集失配（非共焦）：
  • 如果激发光和收集荧光共用透镜，绿光/蓝光聚焦的位置和红光聚焦的位置沿光轴错开几百微米到几毫米，样品表面同时处于“激子没聚焦”或“发射光没收进狭缝”的尴尬状态，局域激发效率大幅下降。

三、导师派给你的任务：“摩尔转角”（更正：莫尔转角 / Moiré Twist Angle）

  • 先纠词：实验物理和光子学里标准叫法是 莫尔转角（Moiré twist angle）（源自法语 *Moiré*，大概率是语音/笔记同音误记为“摩尔”）。生活里两层纱窗稍微错开一个角度叠加，会出现比网格粗得多的大条纹，这就是莫尔超晶格（Moiré superlattice）。
  • 核心几何公式（必记）：两层晶格常数均为 $a$ 的二维周期结构，以小角度 $\theta$ 相对旋转堆叠时，产生的新超晶格周期 $a_M$ 为：

$$a_M = \frac{a}{2\sin(\theta/2)} \approx \frac{a}{\theta}\quad (\text{小角度下 } \theta \text{ 取弧度})$$

例如当 $\theta = 1^\circ = 0.0175\text{ rad}$ 时，$a_M / a = 57.30$——周期直接放大了 57 倍！

  • 为什么扭转一个角度就能出这么多新物理？
  • 平带（Flat Band）与慢光效应：实空间周期暴涨 $\implies$ 倒易（动量/$k$）空间布里渊区剧烈缩小，原本倾斜的能带被反复折叠成密集的子带；当层间耦合强度与周期缩放达成某种平衡（即所谓的“魔角”附近）时，某条能带会被压得几乎水平（平带）。因为群速度 $v_g = \dfrac{1}{\hbar}\dfrac{dE}{dk} \to 0$，光或激子几乎“定在原地”，停驻时间与态密度激增！
  • 莫尔局域势阱：在一个莫尔超胞内部，有的区域两层原子/微结构对齐（AA 堆垛），有的错位（AB 堆垛），导致局部折射率或能隙呈周期性起伏，天然形成阵列式纳米势阱/局域光场，把激子或光子锁在势阱里，极大降低激光/BEC 阈值。
  • 回组必须向师姐确认的两种可能体系（目前未验证）：
  • 路径 A（二维材料莫尔激子 / 莫尔极化激元）：比如把两层单层过渡金属硫族化合物（TMDs，其激子发射多在红光–近红外波段）按特定转角贴在一起形成莫尔激子势阱，再放进 DBR 微腔做强耦合极化激元与 BEC；
  • 路径 B（莫尔光子晶体 / 扭转微腔）：直接通过微纳加工把两层周期光子晶体板（或光栅）转一个 $\theta$ 叠合，不做任何电子激子耦合也能仅靠光子平带产生极高 Q 值局域模与低阈值激光（甚至结合增益损耗做非厄米莫尔拓扑激光）。

1. 高 Q 值：$\Delta\omega$ 怎么变成 $\tau$？$\Delta\lambda$ 到底是什么？

  • 你联想到 $\Delta x \cdot \Delta p \ge \hbar/2$，直觉极准！
  • 它们在数学上确实同源——底层都是傅里叶变换的互易关系（时域越短，频域越宽）。它的时间-能量版本正是 $\Delta E \cdot \Delta t \ge \hbar/2$，两边同除以 $\hbar$ 就是 $\Delta\omega \cdot \Delta t \sim 1$。
  • 不过对一个会漏光的光学腔，不需要套量子不等式，用经典波动就能推出精确等式：
  • 设腔里光强按指数衰减：$I(t) = I_0 e^{-t/\tau}$，其中 $\tau$ 就是光子寿命（能量衰减到原来的 $1/e \approx 37\%$ 所需时间）。因为 $I \propto |E|^2$，电场振幅按 $E(t) = E_0 e^{-t/(2\tau)} \cos(\omega_0 t)$ 衰减。
  • 对这个衰减振荡波做傅里叶变换，频谱不再是一根无限细的竖线，而是一个洛伦兹峰：

$$I(\omega) \propto \frac{1}{(\omega - \omega_0)^2 + \left(\dfrac{1}{2\tau}\right)^2}$$

  • 找峰高降到一半（半高处）的两个频率：令分母变成最小值时的 2 倍，即 $(\omega - \omega_0)^2 = \left(\dfrac{1}{2\tau}\right)^2$，解得 $\omega = \omega_0 \pm \dfrac{1}{2\tau}$。
  • 这两个点之间的宽度叫半高全宽（FWHM），恰好是：

$$\Delta\omega = \left(\omega_0 + \frac{1}{2\tau}\right) - \left(\omega_0 - \frac{1}{2\tau}\right) = \frac{1}{\tau}$$

  • 所以 $Q = \omega_0 \tau = \dfrac{\omega_0}{\Delta\omega}$：光子在腔里活得越久（$\tau$ 大），光谱峰就越细尖（$\Delta\omega$ 小）。
  • $\Delta\lambda$ 在这里代表什么？
  • 光谱仪屏幕横坐标画的通常是波长 $\lambda$（单位 nm），不是角频率 $\omega$。$\Delta\lambda$ 就是光谱仪上那个共振峰“半高处的宽度”（单位 nm）。
  • 因为 $\omega = \dfrac{2\pi c}{\lambda}$，当峰很窄（$\Delta\lambda \ll \lambda_0$）时两边求微分取绝对值：

$$\left|\frac{d\omega}{d\lambda}\right| = \frac{2\pi c}{\lambda^2} = \frac{\omega}{\lambda} \implies \frac{\Delta\omega}{\omega_0} \approx \frac{\Delta\lambda}{\lambda_0}$$

  • 所以在实验室里，拿到一张光谱图，拿峰值中心波长除以半高宽就直接得出 $Q$：

$$Q = \frac{\lambda_0}{\Delta\lambda}$$

  • *具体算例*：如果测出峰位 $\lambda_0 = 650\text{ nm}$、半高宽 $\Delta\lambda = 0.1\text{ nm}$，那么 $Q = 650 / 0.1 = 6500$，反算光子寿命 $\tau = Q/\omega_0 \approx 2.24\text{ ps}$。

2. DBR：光怎么射入？层数怎么选？跟光纤一样吗？

  • 光是不是垂直多层膜射入？
  • 是的。 光是从上方/下方垂直（或一定角度斜向）打在膜面上，试图穿透这一摞膜，而不是顺着某层膜横着传播。
  • 每一层的光学厚度被精确做成目标波长的四分之一（$n_H d_H = n_L d_L = \lambda_0/4$）。这样每经过一个高/低折射率界面反射回来的微弱光线，叠加界面反射的半波损失后，相位完全一致（相长干涉），越叠反射率越高。
  • 几层比较好？不同材料为什么层数不同？层数代表什么区别？
  • 单个界面的反射强弱由两层材料的折射率比值 $n_H / n_L$ 决定（差得越大，单次反射越强）。
  • $N$ 对（即 $2N$ 层）高低折射率膜堆在中心波长处的峰值反射率为（空气 $n_0=1$、基底 $n_s$，顶层为高折射率）：

$$R = \left(\frac{\dfrac{n_0}{n_s}\left(\dfrac{n_L}{n_H}\right)^{2N} - 1}{\dfrac{n_0}{n_s}\left(\dfrac{n_L}{n_H}\right)^{2N} + 1}\right)^2$$

  • 不同材料需要的对数差很远（折射率差越大，层数越少）：
  • 例如介质膜 $\text{TiO}_2/\text{SiO}_2$（$n \approx 2.4 / 1.46$，差很大，基底 $n_s=1.5$）：$N=8$ 对反射率就到 $99.91\%$，$N=10$ 对高达 $99.987\%$；
  • 例如半导体外延膜 $\text{GaAs}/\text{AlAs}$（$n \approx 3.5 / 2.9$，差较小，基底 $n_s=3.5$）：需要 $N=20$ 对才到 $99.94\%$，$N=30$ 对才到 $99.999\%$。
  • 层数多 vs 少的区别：层数越多 $\implies$ 反射率 $R$ 越逼近 $100\%$ $\implies$ 光子越难漏出、$Q$ 值越高；但也不是无限越多越好——层数太多除了生长耗时、膜层应力大、材料自身吸收损耗变大外，如果反射率太高，泵浦光进不去、信号光也漏不出来（探测不到），所以通常把出光面那一侧的 DBR 故意少镀几对。
  • 关键纠偏：腔层像光纤一样靠“高折射率芯包在低折射率里”吗？
  • 不是！你联想到的是“平面波导”（压扁的光纤），它和 DBR 微腔的束缚机制完全不同：
  • 光纤 / 平面波导：光平行于膜面往前跑，靠的是全反射（TIR），所以中间芯层的折射率必须高于包层。
  • DBR 平面微腔：光在上下两面 DBR 之间垂直来回弹跳，靠的是上下两面镜子的布拉格干涉反射，跟全反射没关系！
  • 因此，中间夹着的腔层折射率既可以高，也可以低，甚至可以直接是空气（两个 DBR 中间留一条空气缝）。
  • 至于腔层紧挨着的那一层放高折射率还是低折射率，决定的是界面反射的相位（光从低折射率撞高折射率有 $\pi$ 相移，产生波节；从高撞低无相移，产生波腹）。选哪一层挨着腔层，目的是让腔内驻波的电场最强点（波腹）正好落在发光材料所在的高度。

3. 哈密顿量（Hamiltonian）是什么？跟实验有什么关系？

  • 本质是什么：在经典力学里，$H = T + V$ 就是系统的总能量（动能 + 势能）。在量子力学和光学谐振体系里，系统有一组离散的模式，于是把 $H$ 写成一个能量矩阵：
  • 主对角线元素（如 $E_1, E_2$）：代表如果没有相互作用，每个模式各自的“原生能量”（对应光谱仪里各自原本的峰位）；
  • 非对角线元素（如 $g$）：代表两个模式之间互相交换能量的耦合强度。
  • 为什么实验组会里天天出现它？它跟光谱仪测的数据怎么挂钩？
  • 一句话：你在实验台上拿光谱仪直接测到的峰位（把波长 $\lambda$ 换算成光子能量 $E = hc/\lambda$），就是哈密顿量矩阵 $H$ 的本征值！
  • 看一个最简单的 $2\times 2$ 例子：假设系统里有两个原本能量为 $E_1, E_2$ 的模式，彼此耦合强度为 $g$，写下来就是：

$$H = \begin{pmatrix} E_1 & g \\ g & E_2 \end{pmatrix}$$

解矩阵特征方程 $\det(H - E I) = 0$，算出两个本征值：

$$E_\pm = \frac{E_1 + E_2}{2} \pm \sqrt{\left(\frac{E_1 - E_2}{2}\right)^2 + g^2}$$

  • 对实验者的用途：实验室里没有一把尺子能直接量出“耦合强度 $g$ 是多少”，但光谱仪能直接拍出分裂后的两条峰曲线 $E_+$ 和 $E_-$。把实验拍出来的曲线拿去和 $H$ 的本征值公式拟合，就能把隐藏在里面的物理参数（比如 $g$、失谐量、有效质量）反推出来。所以 $H$ 就是连接物理模型和实验光谱图的翻译器。

4. 什么是平面腔模？为什么反推公式长那样？为什么师姐的图是“带峰值的一元二次曲线”？

  • 什么是平面腔模？结构是什么？
  • 结构：就是一个极薄的“平板三明治”——上面一片平面 DBR 镜子、下面一片平面 DBR 镜子，中间夹一层厚度均匀为 $L$、有效折射率为 $n_{\text{eff}}$ 的平板介质（腔层）。
  • 平面腔模：光在上下两面平行镜子之间反复弹跳，只有满足竖直方向干涉相长（形成驻波）的特定波长才能存活下来，这种允许存在的驻波就叫平面腔模。
  • 零跳跃推导 $\lambda(\theta)$（为什么斜着走波长反而短？）
  • 腔内光的波矢大小为 $k = \dfrac{2\pi n_{\text{eff}}}{\lambda}$。把波矢按空间分解为垂直镜面的分量 $k_z$ 和平行镜面的分量 $k_\parallel$。
  • 第 1 步（镜子锁死了 $k_z$）：上下两面镜子只限制了竖直方向的高度 $L$，所以不管光斜着走还是直着走，竖直方向必须凑出整数个半波长，即 $k_z = \dfrac{m\pi}{L}$ 是一个定死的常数。
  • 第 2 步（正入射 vs 斜入射对比）：
  • 正入射（$\theta = 0^\circ$）时没有水平分量，波矢全在竖直方向：$k_0 = \dfrac{2\pi n_{\text{eff}}}{\lambda_0} = k_z$；
  • 腔内以倾角 $\theta_{\text{in}}$ 斜着走时，竖直分量是斜边的投影：$k_z = k \cos\theta_{\text{in}} = \dfrac{2\pi n_{\text{eff}}}{\lambda(\theta)}\cos\theta_{\text{in}}$。
  • 因为 $k_z$ 始终相等，联立直接消去 $2\pi n_{\text{eff}}$：

$$\frac{\cos\theta_{\text{in}}}{\lambda(\theta)} = \frac{1}{\lambda_0} \implies \lambda(\theta) = \lambda_0 \cos\theta_{\text{in}} = \lambda_0 \sqrt{1 - \sin^2\theta_{\text{in}}}$$

  • *直觉*：直角三角形里，竖直直角边 $k_z$ 被腔厚锁死了，光线一斜，斜边 $k$ 必然比直角边 $k_z$ 更长；而 $k \propto 1/\lambda$，波矢变大意味着波长 $\lambda$ 必须变短。
  • 第 3 步（换算到空气里物镜看到的角 $\theta$）：光从腔里射出到空气（$n_{\text{air}}=1$）遵循高中折射定律：

$$n_{\text{eff}} \sin\theta_{\text{in}} = 1 \cdot \sin\theta \implies \sin\theta_{\text{in}} = \frac{\sin\theta}{n_{\text{eff}}}$$

代入第 2 步，立即得到：

$$\lambda(\theta) = \lambda_0 \sqrt{1 - \left(\frac{\sin\theta}{n_{\text{eff}}}\right)^2}$$

  • 破案！为什么你觉得它该是单调斜率，而师姐的图上是“带峰值的一元二次曲线”？
  • 你只看 $\theta \in [0^\circ, +44.4^\circ]$ 这一半时，它确实是一直往下掉的单调曲线。
  • 但物镜收集的是以光轴为中心、左右对称的一整只光锥！ 横坐标角度是从 $-44.4^\circ$ 扫到 $0^\circ$ 再扫到 $+44.4^\circ$。
  • 看公式里的 $\sin^2\theta$：它是偶函数（往左斜 $20^\circ$ 和往右斜 $20^\circ$ 波长完全相同）。在小角度下用近似 $\sqrt{1 - x} \approx 1 - x/2$ 展开：

$$\lambda(\theta) \approx \lambda_0 - \frac{\lambda_0}{2 n_{\text{eff}}^2}\theta^2$$

  • 这正是一条以 $\theta = 0^\circ$ 为对称轴、开口向下的一元二次抛物线！
  • 最高点（峰值）就在正中央 $\theta = 0^\circ$ 处，波长 $\lambda_0 = 690\text{ nm}$；
  • 往左到 $-44.4^\circ$、往右到 $+44.4^\circ$ 对称滑落，两端截止在 $631\text{ nm}$。
  • *(这也是老师要“反推实际 NA”的直接原因：只要光路后面有遮挡，这条开口向下的抛物线就会在左右两侧被提前“砍断”，截止点就够不到 $631\text{ nm}$。)*

  • 一片磨好的薄透镜，前后两面的球面曲率半径 $R_1, R_2$ 是固定不变的几何常数（对凸透镜，$\frac{1}{R_1} - \frac{1}{R_2} > 0$）。它的焦距 $f$ 由材料折射率 $n$ 决定：

$$\frac{1}{f(\lambda)} = \bigl(n(\lambda) - 1\bigr)\left(\frac{1}{R_1} - \frac{1}{R_2}\right)$$

  • 盯着等式看：右边括号是固定正数，$n(631\text{ nm}) > n(690\text{ nm})$ 直接导致 $n - 1$ 更大 $\implies \dfrac{1}{f}$ 更大 $\implies$ 取倒数后焦距更短：

$$f(631\text{ nm}) < f(690\text{ nm})$$

3. 从公式根源看懂“为什么低 $\to$ 高有半波损失，高 $\to$ 低没有”

$$\text{左侧总电场 } E_i + E_r = E_t \text{（右侧电场）}, \qquad \text{左侧总磁场 } n_1(E_i - E_r) = n_2 E_t \text{（右侧磁场）}$$

把两式相除消去 $E_t$，本质是在逼迫界面两侧的“磁场/电场比值（导纳）”相等：

$$\frac{H_{\text{左}}}{E_{\text{左}}} = n_1 \frac{E_i - E_r}{E_i + E_r} = n_2 = \frac{H_{\text{右}}}{E_{\text{右}}}$$

你看物理因果瞬间透明了：

  • 高 $n_1 \to$ 低 $n_2$（右边 $n_2$ 比左边 $n_1$ 小）：左边需要把比值压低去迁就 $n_2$，那就要求分子变小、分母变大——所以 $E_r$ 必须为正（$E_r > 0$），和入射电场同相，零相移，绝不会出现半波损失！

  • 第 2 步（在腔层里上下往返一趟，算总相位！）：

透进去的光向下走完腔层 $L$ $\to$ 撞底 DBR 内侧 H 反射（低 $\to$ 高，获得 $\pi$ 半波损失）$\to$ 向上走回腔层 $L$ $\to$ 撞顶 DBR 内侧 H 反射（低 $\to$ 高，又获得一次 $\pi$ 半波损失）。

一整个往返周期积累的总相位差为：

$$\Delta\phi_{\text{往返}} = \underbrace{\frac{2\pi}{\lambda_0}\cdot(2 n_c L)}_{\text{上下走 }2L\text{ 的光程相位}} + \underbrace{\pi}_{\text{底镜半波损失}} + \underbrace{\pi}_{\text{顶镜半波损失}} = \frac{4\pi n_c L}{\lambda_0} + 2\pi$$

正如你精准猜到的：两次半波损失凑成 $\pi + \pi = 2\pi$，等效相位归零！所以要让每一轮弹回来的光都跟新透进来的光同相叠加（$\Delta\phi_{\text{往返}} = 2m\pi$），腔层光程就必须设计成：

$$n_c L = m \cdot \frac{\lambda_0}{2}\quad (m = 1, 2, 3, \dots)$$

三、中继透镜（4f）的角度变化 + 为什么场镜在实像面“不影响实像”却能管光瞳？

  • 中继透镜一定会“缩小光线角度”吗？
  • 不一定！中继透镜的核心目的只是把某个平面（实像或后焦面 BFP）原封不动搬到更远的位置。
  • 光线角度怎么变，受工程光学里的拉格朗日不变量约束（横向尺寸 $\times$ 光线张角 = 常数，即 $y_1 u_1 = y_2 u_2$）：
  • 对 4f 系统，横向放大率 $|M| = f_2 / f_1$：
  • 若 $f_2 > f_1$（放大像）：像变大 $M$ 倍，光线角度才缩小 $M$ 倍；
  • 若 $f_2 = f_1$（等大搬运）：像和角度都不变；
  • 若 $f_2 < f_1$（缩小像）：像变小，光线角度反而变大！
  • 补清你没看懂的那句：“场镜放在实像面上不是不影响成像吗？”
  • 你的记忆 100% 正确！ 场镜放在实像面上，对实像来说物距 $u = 0 \implies$ 像距 $v = 0$，确实不改变实像的位置和大小。
  • 关键在于一台显微镜里有两套互相错开的成像面：
  • A 面（样品实像面）：记录“样品上左边还是右边发光”；
  • B 面（物镜后焦面 BFP / 光瞳面）：记录“光往 $0^\circ$ 还是 $30^\circ$ 方向飞”。
  • 当场镜紧贴着 A 面 摆放时：
  • 对 A 面（实像）来说，它在镜片正中间（$u_A = 0$） $\implies$ 对实像位置和大小完全透明（不影响）；
  • 但对远处的 B 面（光瞳/BFP） 来说，B 面离这片场镜有一大段距离（$u_B \neq 0$） $\implies$ 场镜实打实地把 B 面的像重新聚到后面下一片透镜上（也就是把边缘斜飞出去的光线往光轴掰回来，防止渐晕）！

四、焦距相同时，平凸透镜 vs 双凸薄透镜真的没区别吗？

  • 在近轴、薄透镜近似下：完全等价 ✅！

只要焦距 $f$ 相同，无论光是从左射入、还是反射回来从右射入，高斯公式 $\dfrac{1}{l'} - \dfrac{1}{l} = \dfrac{1}{f'}$ 看不出任何差别。

  • 区别全部出现在“跳出近轴薄透镜近似”之后：
  • 减小球差（你猜中了核心，但要分使用场景和朝向！）：

球差来源于大孔径边缘光线在前后两个折射面上拐弯角度分配太不均匀（某一个面折得越狠，球差按偏折角的立方暴涨）。

  • 平行光 $\leftrightarrow$ 焦点（激光准直/聚焦，极不对称场景）：把平凸透镜的凸面朝向平行光、平面朝向焦点时，两面分担的偏折最匀称，球差明显小于等双凸镜；但如果你反着装（平面朝平行光），球差反而比双凸镜还差好几倍！
  • 1:1 对称成像（$u=2f, v=2f$）：两边对称，此时反而是等双凸镜的球差比平凸镜更小。
  • 工程与厚透镜优势：平凸镜磨一个平面成本更低；而且对有一定厚度的平凸镜，其中一个主面正好紧贴凸面顶点，机械架设和量焦距更省事。

五、补上最后一块拼图：为什么不同波长，玻璃折射率 $n(\lambda)$ 会不一样？

你问得太到位了——不能只扔一句“玻璃有色散”就糊弄过去，它的底层物理是电动力学里极经典的洛伦兹电子受迫振动模型：

  • 折射率 $n$ 的微观本质：

光进入玻璃速度变慢（$v = c/n$），不是光子像台球一样撞在原子上被挡住，而是光的交变电场拉着玻璃原子里的束缚电子来回受迫晃动；这些晃动的电子会辐射出次级电磁波，与原入射波叠加后拖慢了总波前的相位——宏观上就表现为 $n > 1$。电子被晃动的幅度越大，滞后越狠，折射率 $n$ 就越大。

  • 为什么不同波长（频率 $\omega$）晃动幅度不一样？

把玻璃分子里的束缚电子看成挂在弹簧上的小球，它有一个天生的固有共振频率 $\omega_0$。对透明光学玻璃来说，电子束缚得很紧，这个固有吸收频率落在紫外波段（比可见光频率高很多，即 $\omega_{\text{可见光}} < \omega_0$）。

按大学物理的受迫振动公式，驱动频率 $\omega$ 越逼近固有频率 $\omega_0$，电子振幅越大（电极化强度 $\propto \dfrac{1}{\omega_0^2 - \omega^2}$）。

  • 直接落到 631 nm vs 690 nm：
  • 波长越短 $\implies$ 光频率 $\omega = 2\pi c/\lambda$ 越高 $\implies$ 离玻璃的紫外固有频率 $\omega_0$ 更近！
  • 所以 $631\text{ nm}$ 比 $690\text{ nm}$ 把玻璃里的电子晃得更猛烈 $\implies$ 相位滞后更大 $\implies$ $n(631\text{ nm}) > n(690\text{ nm})$！
  • *(把 $\dfrac{1}{\omega_0^2 - \omega^2}$ 在 $\omega \ll \omega_0$ 下做泰勒展开，出来的正是前两轮提到的柯西公式 $n(\lambda) = A + B/\lambda^2$！)*

这样，电子紫外共振 $\xrightarrow{\text{受迫振动}}$ 短波 $n$ 更大 $\xrightarrow{\text{磨镜者公式}}$ 短波焦距 $f$ 更短 $\xrightarrow{\text{高斯公式}}$ 短波像距 $v$ 更短（轴向色差）——整条链从微观电子到宏观光路，现在一块砖都不缺了！
