### 一、 三项核心升级落地详情

1. **外置共享侧边栏 `sidebar.js` + 网页顶栏 `.md` 直链按钮**
   - **`template.html`**：移除页面内联侧边栏列表 `{{SIDEBAR_ITEMS}}` 与全局同步时间戳，改为挂载 `data-conv-id` / `data-base-prefix` 属性并引入共享脚本 `sidebar.js`，通过安全 DOM API（`textContent`）渲染全部历史对话与更新时间；静态 `<aside>` 固定收敛至 **`423` 字符**，彻底消除历史 `.html` 跨文件 Git 写放大。
   - **顶栏新增 AI 分享入口**：在 `.header-actions` 新增 **`📄 纯净 .md`** 直达链接、**`复制 AI 纯净版 (.md)`** 与 **`复制对话直链`** 按钮（通过 `new URL(relPath, window.location.href).href` 解析标准绝对链接，并附 `textarea` 降级复制兼容与移动端自动换行）。

2. **超长对话顺序分片机制（`./c/<id>.p1.md`, `p2.md` ...）**
   - 在 `sync_share.ps1` 中新增 `Split-TurnIntoPieces` 与 `Build-AgentChunks`：当会话 `.md` 超出 `3,600` 字符或需要多片才能承载时，按**时间正序**（`T1 -> TN`）切分为单片严格 `<= 3,300` 字符的 `.pK.md` 分片文件；即便单轮正文自身超过 `2,850` 字符也会按换行边界切分为 `Part a/b` 子片，且每片自带 `Main` / `Prev` / `Next` 导航头尾与轮次范围标注。
   - 在主 `.md` 的 `[BREAKPOINT SUMMARY]` 中自动嵌入紧凑分片索引（如 `Pages (15 chunks, <=3.3k each, chronological): ./c0f340d4...p1.md(T1) .. ./c0f340d4...p15.md(T15) [pattern: ...p{1..15}.md]`），并用动态预算限制 `[USER TIMELINE]` 确保摘要区恒定 `<= 3,150` 字符；同时自动清理缩短会话遗留的孤立旧分片。

3. **基于文件指纹的本地增量解析缓存（`sync_cache.json`）**
   - 在插件目录引入 `sync_cache.json`（位于 `site\` 外，不进 Git 仓库），同时校验 `sync_share.ps1` 与 `template.html` 的双文件修改时间戳+字节数签名（`generator_sig`），以及各会话 `transcript.jsonl` / `transcript_full.jsonl` 的精确 UTC ticks 与长度并校验输出产物存在性。
   - 未变更的历史会话直接复用缓存元数据，跳过 JSON 解析、HTML/MD 渲染与磁盘写入；若 `index.html` 指向会话发生变化则按需单条补读。
