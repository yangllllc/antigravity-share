### [T4/4] Antigravity Assistant
先把两个关键现象说清楚：**你没有看漏，也无法在不改 Antigravity 软件主程序的前提下，把第三方插件硬塞进 `Settings` 菜单或左侧主栏成为独立一级按钮**。但你已经可以通过对话按钮、`Customizations`（插件中心）或对话右侧面板直接打开完整中文界面。

---

## 一、为什么会这样？（实查结论）

1. **为什么左侧主栏和 `Settings` 里没有单独多出这个插件按钮**
   - 核查 Antigravity 主程序前端逻辑与运行时开关（`GetMendelFlags`）：左侧主栏插件独立分区（`x2c` / `pluginSidebarSection`）当前被特性开关 `enable-plugin-sidebar-section` 关闭；`Settings` 菜单项也是内置硬编码列表（`Account / General / Appearance / Notifications / Customizations / Browser / App / Shortcuts / Models / Developer / Running`）。
   - 第三方插件只能挂载到 Antigravity 开放的两个原生位置：**Customizations（插件中心）** 与 **对话右侧辅助面板（Extensions / Aux Pane）**。
2. **为什么观察一圈发现“多了两个项目”**
   - Antigravity 的语言服务会自动为带 Web UI 服务的插件创建一个**后台沙盒载体项目**。目前你的本地项目共有 4 个非临时项目 ID：
     - 你的真实业务项目：`Zemax`（已恢复到首位）和 `光路`；
     - 插件服务载体项目：`antigravity-archive-manager/archive_manager`（我们刚创建的归档管理后台服务）和 `swarm/swarm_board`（Antigravity 内置多智能体扩展自带的后台服务）。
   - 主界面左侧栏会隐藏这类带 `sidecar` 标记的服务载体，但 **`Settings` 设置页左侧的 `Projects` 列表（`YRb`）没有过滤掉它们**，所以你会同时看到它们。**不要手动删除这两个带 `/` 名称的项目**（插件面板里的“项目列表”已自动隔离它们，不会让你误删）。

---

## 二、三种打开与使用方式（推荐按方式 1 最快）

已在插件目录新增中文说明文档 `README.md`，现在整个插件共 12 个文件，均已通过测试与实时服务检查：

### 方式 1：在本对话内一键直达（最快）
直接点击下面这个内置快捷入口，会在右侧展开完整的中文管理界面：

[打开归档与项目管理面板](sidecar://antigravity-archive-manager/archive_manager/)

### 方式 2：从 Antigravity 原生界面“插件中心”打开
如果你当前没有打开对话、或者想从一个固定管理入口进去：
1. 点击下方入口（或打开左侧栏 / Settings 里的 **Customizations -> Installed**）：
   [归档与项目管理器](customization://antigravity-archive-manager)
2. 进入插件详情页后：
   - 顶部会显示插件中文说明和 **3 个快捷指令**（点击即可直接发起对应操作对话）；
   - 向下滚动到 **UI Extensions**，点击 **`归档管理`**，在弹窗里点击 **`Open in Side Pane`**，即可直接在右侧面板打开管理界面。

### 方式 3：在任意对话中调出或用 `/archive-manager`
- **右侧面板菜单**：打开任意对话 -> 展开右上角辅助面板（Aux Pane）-> 点击右上角 **`+`**（或概览区 **`Extensions`**）-> 选择 **`归档与项目管理`**。
- **命令触发**：在聊天框输入 **`/archive-manager`**，或直接打字告诉我需求（例如“查看已归档对话并恢复”“删除某条对话”）。

---

## 三、打开面板后的操作流程

1. **已归档对话 / 全部对话**：上方支持关键字搜索与状态筛选；单条点**恢复**或勾选多条批量点**恢复到侧边栏 / 删除**（取消归档后立即回到主侧边栏）。
2. **项目与侧栏诊断**：只展示你的真实业务项目（当前为 `Zemax` 和 `光路`），自动检测诸如 `projectsOrder` 缺失、折叠或未对齐等异常并一键修复。
3. **回收站安全保护**：删除对话默认先进入插件的 `.trash/` 回收站目录，可随时还原；确认不再需要后再在回收站内**彻底删除**（当前还检测到 4 条历史孤立索引残留，可在面板内查看后决定是否清理）。
