| 网站会查什么 | 普通浏览器 + VPN 的问题 | OpenBrowser 正确做法及原因 |

| :--- | :--- | :--- |

| 1. 网络出口与断线防漏 | 选直连时，VPN 一旦掉线或未开就会直接暴露国内 IP；且 IPv6 / WebRTC UDP 可能绕过代理直连 | 必须选「代理模式」指向 http://127.0.0.1:12450（不要选「本地直连」）。源码实测确认：只有「代理模式」才会启用断网熔断（VPN 不通直接禁止启动，绝不偷偷回退国内网络）、自动禁用 IPv6（--disable-ipv6）、焊死非代理 UDP，且每次启动前强制重新查一次最新出口 IP，不会吃到上次的旧缓存。 |

| 2. 时区 / 语言 / 经纬度一致性 | IP 在美国洛杉矶，但 Windows 系统时区仍是 Asia/Shanghai、语言是 zh-CN，一眼穿帮 | 语言、时区、地理位置全设为「基于出口 IP」，勾选「每次启动检测出口 IP」和「检测后自动对齐指纹」。以后你在 SakuraCat 切美西、美东甚至日/英节点，只需关掉窗口再重新点「启动」，它会自动把时区、语言、坐标同步成新 IP 的所在地。 |

  • Google 网页端最容易被自动化脚本和批量号滥用，因此服务端专门设了一道严厉的 p=no_access 信任分闸门——要求账号具备“长期、连续、稳定且无异常切换的使用历史（consistent history of abuse-free activity）”。
