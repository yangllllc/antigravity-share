#### P0：成本熔断、安全暴露与审核一致性
1. **赠额免费槽防超额按量扣费（TokenHub / 百炼）**：实机库中已启用腾讯云 TokenHub 国际站 `hy4-flash`（免费包耗尽后按量计费）。在 `ai-router.ts`、`ai-settings.ts` 与 `AiPanel.tsx` 中对 `tokenhub*` / `dashscope*` 槽位默认开启 **40 次/日、300 次累计** 持久化硬上限（`ai_channel_usage` 原子预占，触顶自动熔断换槽，且 `testAiConnection` 共用同一账本，前端可查看实时用量与调整上限）。
2. **同济周 Token 原子硬上限与结算容错**：原逻辑只原子扣减请求次数，Token 仅在事后追加且结算报错被吞。已在 `ai-router.ts` 改为单事务同时原子预占 `req_count + 1` 与保守估算 `token_est`，并按剩余预算钳位 `maxTokens`；结算落库失败时保留保守预占并触发 300s 同济退避冷却。
3. **手动补译/补审与统计口径断裂（含实机库 226 条预译项）**：实机库中有 226 条 `translatedOnly`（`ai IS NOT NULL AND ai_keep IS NULL`）此前被 `aiStats().pending` 和 `backfillAi("pending")` 漏掉，同时在最近样本中被误判为红叉拦截；旧版 `backfillAi("english")` 还会跳过时政严审并覆盖 `ai_keep`/`summaryZh`。已在 `ai-admin.ts` 拆清语义：`mode="english"` 仅走免费池补译 `titleZh`/`takeaway` 且保留 `ai_keep=NULL`；`pending`/`recent`/`rejected` 纳管 `ai_keep IS NULL`，时政条目分流走 `POLITICS_STRICT_PROMPT` 并经共享 `applyVerdictToItem` 强制 `<4★ => keep=0`、保留 `summaryZh` 并合并 AI 标签。
4. **单机退役路由彻底下线与 API 404 收口**：在 `routes.ts`、`index.ts` 与 `OpsPanel.tsx` 移除旧版多用户/OAuth/邀请码/Push/CookieRunner/外部领取器路由（`/api/cookies*`、`/api/external-tools`、`/api/push*`、`/api/ingest*`、`/api/me/*`、`/api/admin/invites|users|...`），并在 SPA 兜底前增加 `app.all("/api/*", 404 JSON)`。
5. **Reddit `r/LocalLLaMA` 与社区 RSS 纵深防噪**：在 `collectors/index.ts` 为 `rss-reddit-localllama` 种子补开 `communityFilter: true`，并在 `collectors/rss.ts` 对 `kindHint="community"` 源默认启用社区防噪（覆盖存量库旧配置）。
6. **启动日志脱敏**：在 `index.ts` 移除控制台直接打印明文 6 位 `mobile.pin`（改为仅在网页「手机同步」卡片内查看）。
