how can i change antigravity change usage language from English to Chinese

Antigravity Assistant

There are two separate settings here: the interface language and the language the AI agent replies in.

1. Interface language (menus, buttons, settings)

Antigravity IDE is built on VS Code, so you change the language the same way:

  • Press Ctrl+Shift+X to open Extensions.
  • Search for Chinese (Simplified) Language Pack and click Install. Use Chinese (Traditional) if you want that instead.
  • Press Ctrl+Shift+P and run Configure Display Language.
  • Choose 中文(简体) / zh-cn, then click Restart.
[!NOTE]
The language pack only translates the parts that come from VS Code. Antigravity's own panels, such as the Agent Manager, may still show some English. I couldn't find an official Antigravity language setting in the docs I have. Check https://antigravity.google/docs or the changelog to see if one has been added.

2. Agent reply language

To have me reply in Chinese, you can:

  • Ask in the chat: say "请用中文回复" or simply write to me in Chinese.
  • Make it permanent: add a global rule such as Always respond in Simplified Chinese. (请始终使用简体中文回复。) under Customizations → Rules. Rules docs: https://antigravity.google/docs/rules-workflows
