### 一、菲涅耳公式推导 + 隐含前提 + 半波损失的电磁根源

#### 1. 隐含前提（不是任何情况都能直接套正入射公式！）
下面这组最简公式依赖 **4 个前提**：
1. 界面两侧均为**线性、均匀、各向同性、无吸收（折射率 $n_1, n_2$ 为实数）、非磁性（$\mu_1 = \mu_2 = \mu_0$）**的电介质；
2. 界面是**光学级光滑平面**（粗糙度远小于波长）；
3. **正入射**（$\theta_i = 0^\circ$；如果是斜入射，电场平行/垂直入射面表现不同，必须拆成 s 偏振和 p 偏振两套更长的菲涅耳公式）；
4. 仅算**单次界面**（若有多层膜，需要把所有界面的多次反射波叠加，即传输矩阵法）。

#### 2. 从麦克斯韦边界条件推导（正入射，零跳跃）
设光沿 $+z$ 方向从介质 1（$n_1$）垂直射向介质 2（$n_2$），界面在 $z=0$：
* **电场参考方向约定**：把入射、反射、透射电场都先统一标为沿 $+x$ 轴正方向（$\vec{E}_i = E_i\hat{x}$、$\vec{E}_r = E_r\hat{x}$、$\vec{E}_t = E_t\hat{x}$）。如果最后解出 $E_r$ 与 $E_i$ 反号，就意味着反射波实际指向 $-x$（相位翻转 $\pi$）。
* **由麦克斯韦方程写磁场**：平面电磁波满足 $\vec{H} = \dfrac{n}{\eta_0}(\hat{k} \times \vec{E})$（其中 $\eta_0 = \sqrt{\mu_0/\varepsilon_0}$ 为真空波阻抗，$\hat{k}$ 为传播方向单位矢量）：
  * 入射波向 $+z$ 传：$\hat{z}\times\hat{x} = +\hat{y} \implies H_i = +\dfrac{n_1}{\eta_0} E_i$；
  * **反射波掉头向 $-z$ 传（半波损失的伏笔就在这！）**：$(-\hat{z})\times\hat{x} = -\hat{y} \implies H_r = -\dfrac{n_1}{\eta_0} E_r$；
  * 透射波向 $+z$ 传：$\hat{z}\times\hat{x} = +\hat{y} \implies H_t = +\dfrac{n_2}{\eta_0} E_t$。
* **界面边界条件（$z = 0$ 处切向电场连续、切向磁场连续）**：
  $$\begin{cases} E_i + E_r = E_t \\ n_1 E_i - n_1 E_r = n_2 E_t \end{cases}\quad\text{（磁场方程两边已消去 }1/\eta_0\text{）}$$
* **联立求解**：把第 1 式的 $E_t = E_i + E_r$ 代进第 2 式：
  $$n_1(E_i - E_r) = n_2(E_i + E_r) \implies (n_1 - n_2)E_i = (n_1 + n_2)E_r$$
  立刻得到**振幅反射系数 $r$** 与 **振幅透射系数 $t$**：
  $$r = \frac{E_r}{E_i} = \frac{n_1 - n_2}{n_1 + n_2}, \qquad t = \frac{E_t}{E_i} = 1 + r = \frac{2n_1}{n_1 + n_2}$$
* **换成光强反射率 $R$ 和光强透射率 $T$**：
  光强由坡印廷矢量给出 $I = \dfrac{n}{2\eta_0}|E|^2$（注意前面乘着折射率 $n$！）：
  * 反射波和入射波在同一介质 $n_1$ 中，$n_1$ 消掉：
    $$R = \frac{I_r}{I_i} = r^2 = \left(\frac{n_1 - n_2}{n_1 + n_2}\right)^2$$
  * 透射波进入了介质 $n_2$，**不能直接写成 $t^2$**，必须乘折射率比 $\dfrac{n_2}{n_1}$：
    $$T = \frac{I_t}{I_i} = \frac{n_2}{n_1} t^2 = \frac{4n_1 n_2}{(n_1 + n_2)^2}$$
  * 验算能量守恒：$R + T = \dfrac{(n_1 - n_2)^2 + 4n_1 n_2}{(n_1 + n_2)^2} = 1$ ✅。

#### 3. 从公式根源看懂“为什么低 $\to$ 高有半波损失，高 $\to$ 低没有”
死盯上面那两条边界方程：
$$\text{左侧总电场 } E_i + E_r = E_t \text{（右侧电场）}, \qquad \text{左侧总磁场 } n_1(E_i - E_r) = n_2 E_t \text{（右侧磁场）}$$
把两式相除消去 $E_t$，本质是在逼迫**界面两侧的“磁场/电场比值（导纳）”相等**：
$$\frac{H_{\text{左}}}{E_{\text{左}}} = n_1 \frac{E_i - E_r}{E_i + E_r} = n_2 = \frac{H_{\text{右}}}{E_{\text{右}}}$$
你看物理因果瞬间透明了：
* **低 $n_1 \to$ 高 $n_2$（右边要求的磁/电比 $n_2$ 比左边 $n_1$ 大）**：左边想把比值 $n_1 \dfrac{E_i - E_r}{E_i + E_r}$ **抬高**去够到 $n_2$，唯一的数学办法是让分子变大、分母变小——这**强迫 $E_r$ 必须为负（$E_r < 0$）**！因为反射波往回跑时磁场天然自带负号，只有把反射电场翻个个儿（相位跳变 $\pi$，即半波损失），反射磁场才能转成正号来“增援”左边磁场，同时把界面电场压低，两边 $E$ 和 $H$ 才接得上！
* **高 $n_1 \to$ 低 $n_2$（右边 $n_2$ 比左边 $n_1$ 小）**：左边需要把比值**压低**去迁就 $n_2$，那就要求分子变小、分母变大——所以 **$E_r$ 必须为正（$E_r > 0$）**，和入射电场同相，零相移，绝不会出现半波损失！
*(最形象的力学类比：轻绳接重绳，波撞到几乎不动的重绳节点上被“按死”，反射波必须倒扣过来——半波损失；重绳接轻绳，接头处甩得飞起，反射波正着回来。)*

### 三、中继透镜（4f）的角度变化 + 为什么场镜在实像面“不影响实像”却能管光瞳？

1. **中继透镜一定会“缩小光线角度”吗？**

     * 若 $f_2 < f_1$（缩小像）：像变小，光线角度反而**变大**！

### 一、傅里叶变换的物理意义 + 为什么会有 $\omega_0$ + Q 值到底图什么

1. **傅里叶变换在物理上到底是什么？为什么换个变量就有物理意义？**
   * 物理本质只有一句话：**任何随时间起伏的波形，都可以拆成一堆不同频率的纯正弦波（单色光）叠加。**
   * 你弹一个钢琴和弦，麦克风录到的是随时间晃动的一条曲线 $E(t)$；傅里叶变换就是把这团曲线放进**三棱镜 / 光谱仪**，告诉你“里面含多少 Do、多少 Mi、多少 Sol”（频率函数 $\tilde{E}(\omega)$）。
   * **光谱仪本身就是一台硬件傅里叶变换仪**。所以把时域波形做傅里叶变换，算出来的就是光谱仪屏幕上真实看到的分布。
2. **你抓到的漏洞：$\omega_0$ 怎么变出来的？**
   * 你怀疑得完全对——**不是对光强 $I(t)$ 做傅里叶变换，而是对电场 $E(t)$ 做傅里叶变换！**
   * 写全这 2 行，就彻底严丝合缝了（用复数表示简谐波 $E(t) = E_0 e^{-t/(2\tau)} e^{-i\omega_0 t}$）：
     $$\tilde{E}(\omega) = \int_0^{+\infty} E_0 e^{-t/(2\tau)} e^{-i\omega_0 t} \cdot e^{i\omega t}\,dt = E_0 \int_0^{+\infty} e^{\left[i(\omega - \omega_0) - \frac{1}{2\tau}\right]t}\,dt = \frac{E_0}{\dfrac{1}{2\tau} - i(\omega - \omega_0)}$$
   * 光谱仪的相机测不到电场正负振荡，只能测**光强（振幅模的平方）**：
     $$I(\omega) = |\tilde{E}(\omega)|^2 = \frac{E_0^2}{(\omega - \omega_0)^2 + \left(\dfrac{1}{2\tau}\right)^2}$$
   * 这就是为什么 $\omega_0$ 和 $\tau$ 会同时出现在 $I(\omega)$ 里。
3. **Q 值本身的意义是什么？（不只是换算寿命）**
   * Q 值的底层物理定义是无量纲的**“攒能量打分”**：
     $$Q = 2\pi \times \frac{\text{腔内储存的能量}}{\text{光振动 1 个周期内漏掉的能量}}$$
   * **为什么不直接报寿命 $\tau$，非要造一个 $Q$？**
     * 同样活 $1\text{ ps}$：对微波（周期 $100\text{ ps}$）来说连 1 个周期都没震完就死了（极烂的腔，$Q < 1$）；但对 $650\text{ nm}$ 红光（周期只有 $2.17\text{ fs}$）来说，这 $1\text{ ps}$ 里它已经疯狂来回震荡了 **461 个周期**（对应的 $Q \approx 2898$）！
     * 所以 $Q$ 剥离了波段差异，直接告诉你**光子在死掉前能震荡多少个周期、光谱峰有多锐利（$\lambda_0/\Delta\lambda$）**。

### 二、DBR 反射公式、半波损失，以及“平面微腔”到底长什么样

1. **为什么单界面的反射强弱由折射率比值决定？半波损失从哪来？**
   * 你提到的“上下表面光程差 + 半波损失 = $2\pi$ 整数倍”，解释的是多层叠加时的**相位相长条件**；而**光撞到单个界面时到底能弹回百分之多少**，是由电磁波边界条件导出的**菲涅耳公式（正入射）**决定的：
     $$r = \frac{n_1 - n_2}{n_1 + n_2} = \frac{1 - n_2/n_1}{1 + n_2/n_1}$$
   * 这个最简公式同时回答了你两个问题：
     * **为什么看比值 $n_2/n_1$？** 若 $n_1 = n_2$（两边材料一样），$r = 0$，一丁点都不反射；$n_2/n_1$ 偏离 $1$ 越远，单次反弹比例 $|r|$ 越大。
     * **半波损失的原理是什么？** 当光从**低折射率 $n_1$ 射向高折射率 $n_2$** 时，$n_1 - n_2 < 0 \implies r < 0$。振幅前面多出一个**负号**，对正弦波来说 $\cos(\omega t + \pi) = -\cos(\omega t)$，这就是相位突变 $\pi$（半个波长）——也就是“半波损失”！反过来高射向低时 $r > 0$，没有半波损失。
   * *(顺带确认：上一轮给的那个大 $R$ 公式，算的就是**一整片由 $N$ 对膜组成的 DBR 镜子**在中心波长处的**总光强反射率** $I_{\text{反射}}/I_{\text{入射}}$。)*

### 三、$k$ 的分解、$k_z$ 筛选逻辑、$k_\parallel$ 干不干扰，以及“图像不对称”

1. **$k$ 分成 $k_z$ 和 $k_\parallel$，是分成两束垂直的光吗？**
   * **不是两束光，是同一束光的矢量投影！** 类比斜着扔出一颗球，它的速度 $\vec{v}$ 可以分解成竖直分速度 $v_z$ 和水平分速度 $v_x$，但空中只有一颗球。
   * 波矢 $\vec{k}$ 方向就是光的传播方向，$k_z$ 表示“往竖直方向走 1 米相位转多少”，$k_\parallel$ 表示“往水平方向走 1 米相位转多少”。
2. **为什么 $k_z$ 始终相等？$k_\parallel$ 会不会干扰竖直干涉？**
   * **你的理解完全正确 ✅**：并不是所有光天生 $k_z$ 相同，而是两面平行镜子像个筛子——光在上下镜之间弹一趟（竖直路程 $2L$），只有满足竖直相位变化 $2 k_z L = 2m\pi$（即 $k_z = m\pi/L$）的光才会干涉增强存活，不满足的直接相消死掉。所以波长变短（总 $k$ 变大）时，必须歪到对应的角度 $\theta$ 把 $k_z = k\cos\theta_{\text{in}}$ 压回 $m\pi/L$，才能通过筛子被你测到。
   * **$k_\parallel$ 不会干扰竖直干涉**：因为两面镜子在水平方向是完全平整均匀的，光反射时（入射角=反射角）**水平分量 $k_\parallel$ 纹丝不动**，只有竖直分量反复翻转 $k_z \to -k_z$。你可以想象一束光一边在上下镜间垂直弹跳形成驻波，一边顺着水平方向匀速滑行，两个方向完全解耦。
3. **你们组博一师兄提的“实际图像不是严格对称的偶函数”太真实了！**
   * 理论公式 $\lambda(\theta)$ 是严格偶函数，但实验上 CCD 拍出来的抛物线经常一侧长、一侧短或顶点偏心，最常见的 4 个实验原因正好连回你学的光路：
     1. **样品放歪了（有小倾角 $\Delta\theta$）**：样品法线不垂直于物镜光轴，导致顶点偏移，左右收集角变成 $-44.4^\circ + \Delta\theta$ 和 $+44.4^\circ + \Delta\theta$；
     2. **中继光路或光谱仪狭缝偏心**：两镜准直没把 BFP 圆心严格打在狭缝中心，导致一侧大角度被镜框/狭缝提前切边；
     3. **腔厚不均匀（有楔角 wedge）**：样品表面厚度有微小坡度；
     4. **材料/结构本身不对称**（例如各向异性晶体或有特定取向的微纳结构）。

### 四、中继透镜 vs 场镜、师姐的平凸透镜，以及打通你的《工程光学》断层！

1. **中继透镜 vs 你学过的“场镜（Field lens）”**
   * **场镜**：一定放在**中间实像面（或紧贴像面）**上。它不改变实像的位置和大小，专门把边缘视场跑歪的主光线往回“兜进”下一片透镜的口径里，防止画面四周变暗（渐晕）——本质上是在**把光瞳（孔径光阑 / BFP）重新成像**到下一级透镜上。
   * **中继透镜（Relay lens，如 4f 系统）**：放在物和像之间，核心任务是把一整个平面（样品实像面，或者物镜后焦面 BFP）**长距离搬运/重新成像**到远处的探测器或光谱仪狭缝上。
   * *两者联系*：如果先用筒镜成了一个样品中间实像，在这个实像面上放一片透镜去中继后焦面 BFP，那这片透镜既扮演了“对实像无感的场镜”，又干了“搬运 BFP”的活！

2. **用你会的《工程光学》单球面公式，4 行零跳跃打通“单球面 $\to$ 磨镜者公式 $\to$ 主面”！**
   你既然会《工程光学》里的**单个折射球面公式**（光从左向右，顶点右侧为正、左侧为负）：
   $$\frac{n'}{l'} - \frac{n}{l} = \frac{n' - n}{r}$$
   一片在空气中（$n_0 = 1$）、折射率为 $n$、前后两面曲率半径为 $r_1, r_2$ 的薄透镜（厚度 $d \approx 0$），无非就是**连续套用两次你已经会的单球面公式**：
   * **第 1 面折射**（空气 $1 \to$ 玻璃 $n$，半径 $r_1$）：
     $$\frac{n}{l'_1} - \frac{1}{l_1} = \frac{n - 1}{r_1}$$
   * **第 2 面折射**（玻璃 $n \to$ 空气 $1$，半径 $r_2$）：因为透镜极薄（$d \approx 0$），第 1 面的像距直接就是第 2 面的物距（$l_2 = l'_1$）：
     $$\frac{1}{l'_2} - \frac{n}{l'_1} = \frac{1 - n}{r_2} = -\frac{n - 1}{r_2}$$
   * **两式直接相加**（中间项 $\dfrac{n}{l'_1}$ 一正一负当场抵消！）：
     $$\frac{1}{l'_2} - \frac{1}{l_1} = (n - 1)\left(\frac{1}{r_1} - \frac{1}{r_2}\right)$$
   * **令平行光入射（$l_1 = -\infty$）**，此时像距 $l'_2$ 就是像方焦距 $f'$——**磨镜者公式就这么来的！**
     $$\frac{1}{f'} = (n - 1)\left(\frac{1}{r_1} - \frac{1}{r_2}\right)$$
   * **再接上你会的“主面”**：
     * 刚才假设了厚度 $d = 0$，此时前后两个主面 $H, H'$ **重叠在透镜中心**，所以物距、像距直接从镜片中心量。
     * 如果镜片有真实厚度 $d > 0$（厚透镜），第 2 面的物距变成 $l_2 = l'_1 - d$，中间项消不掉了，严格算下来焦距多出一项（《工程光学》里的古尔斯特兰德公式）：
       $$\frac{1}{f'} = (n - 1)\left(\frac{1}{r_1} - \frac{1}{r_2} + \frac{(n - 1)d}{n r_1 r_2}\right)$$
       为了继续偷懒用你熟悉的高斯公式 $\dfrac{1}{l'} - \dfrac{1}{l} = \dfrac{1}{f'}$，工程光学才把厚透镜等效成两个错开的**主面 $H, H'$**，只要物距从 $H$ 量、像距从 $H'$ 量，公式就和薄透镜长得一模一样！

3. **现在你立刻能自己审视师姐关于“平凸透镜”的话了！**
   * 把上面刚推出来的公式里第 2 面改成平面（曲率半径 $r_2 = \infty$）：
     $$\frac{1}{f'} = (n - 1)\left(\frac{1}{r_1} - \frac{1}{\infty}\right) = \frac{n - 1}{r_1}$$
   * **师姐说对的部分**：平面那一侧光焦度为 $0$，确实只靠凸的那一面提供聚焦能力。
   * **容易被误导的两个地方**：
     1. **平凸镜并不是为了“只有一个焦距”**：哪怕双凸透镜两面弯曲度完全不同，在空气中对**同一波长**也只有一个焦距大小（$|f|=|f'|$）；而对**不同波长**，因为公式里还乘着 $(n(\lambda) - 1)$，平凸镜照样存在色差（$631\text{ nm}$ 折射率大，焦距仍然比 $690\text{ nm}$ 短）！
     2. **平面那一面不是“只反射透射、不折射”**：光线斜着打进平面依然严格按折射定律拐弯（只是没弯曲度，无法单独聚焦）。另外实验中选平凸透镜通常是为了**减小球差**（让平行光打向凸面、汇聚光从平面出，且其后主面或前主面刚好落在凸面顶点上，方便计算定位）。

### 1. 高 Q 值：$\Delta\omega$ 怎么变成 $\tau$？$\Delta\lambda$ 到底是什么？

* **你联想到 $\Delta x \cdot \Delta p \ge \hbar/2$，直觉极准！**
  * 它们在数学上确实同源——底层都是**傅里叶变换的互易关系**（时域越短，频域越宽）。它的时间-能量版本正是 $\Delta E \cdot \Delta t \ge \hbar/2$，两边同除以 $\hbar$ 就是 $\Delta\omega \cdot \Delta t \sim 1$。
  * 不过对一个会漏光的光学腔，不需要套量子不等式，用经典波动就能推出**精确等式**：
    1. 设腔里光强按指数衰减：$I(t) = I_0 e^{-t/\tau}$，其中 **$\tau$ 就是光子寿命**（能量衰减到原来的 $1/e \approx 37\%$ 所需时间）。因为 $I \propto |E|^2$，电场振幅按 $E(t) = E_0 e^{-t/(2\tau)} \cos(\omega_0 t)$ 衰减。
    2. 对这个衰减振荡波做傅里叶变换，频谱不再是一根无限细的竖线，而是一个**洛伦兹峰**：
       $$I(\omega) \propto \frac{1}{(\omega - \omega_0)^2 + \left(\dfrac{1}{2\tau}\right)^2}$$
    3. 找峰高降到一半（半高处）的两个频率：令分母变成最小值时的 2 倍，即 $(\omega - \omega_0)^2 = \left(\dfrac{1}{2\tau}\right)^2$，解得 $\omega = \omega_0 \pm \dfrac{1}{2\tau}$。
    4. 这两个点之间的宽度叫**半高全宽（FWHM）**，恰好是：
       $$\Delta\omega = \left(\omega_0 + \frac{1}{2\tau}\right) - \left(\omega_0 - \frac{1}{2\tau}\right) = \frac{1}{\tau}$$
  * 所以 $Q = \omega_0 \tau = \dfrac{\omega_0}{\Delta\omega}$：**光子在腔里活得越久（$\tau$ 大），光谱峰就越细尖（$\Delta\omega$ 小）**。

* **$\Delta\lambda$ 在这里代表什么？**
  * 光谱仪屏幕横坐标画的通常是**波长 $\lambda$**（单位 nm），不是角频率 $\omega$。**$\Delta\lambda$ 就是光谱仪上那个共振峰“半高处的宽度”**（单位 nm）。
  * 因为 $\omega = \dfrac{2\pi c}{\lambda}$，当峰很窄（$\Delta\lambda \ll \lambda_0$）时两边求微分取绝对值：
    $$\left|\frac{d\omega}{d\lambda}\right| = \frac{2\pi c}{\lambda^2} = \frac{\omega}{\lambda} \implies \frac{\Delta\omega}{\omega_0} \approx \frac{\Delta\lambda}{\lambda_0}$$
  * 所以在实验室里，拿到一张光谱图，拿峰值中心波长除以半高宽就直接得出 $Q$：
    $$Q = \frac{\lambda_0}{\Delta\lambda}$$
  * *具体算例*：如果测出峰位 $\lambda_0 = 650\text{ nm}$、半高宽 $\Delta\lambda = 0.1\text{ nm}$，那么 $Q = 650 / 0.1 = 6500$，反算光子寿命 $\tau = Q/\omega_0 \approx 2.24\text{ ps}$。

### 2. DBR：光怎么射入？层数怎么选？跟光纤一样吗？

1. **光是不是垂直多层膜射入？**
   * **是的。** 光是从上方/下方**垂直（或一定角度斜向）打在膜面上**，试图穿透这一摞膜，而不是顺着某层膜横着传播。
   * 每一层的光学厚度被精确做成目标波长的四分之一（$n_H d_H = n_L d_L = \lambda_0/4$）。这样每经过一个高/低折射率界面反射回来的微弱光线，叠加界面反射的半波损失后，**相位完全一致（相长干涉）**，越叠反射率越高。
2. **几层比较好？不同材料为什么层数不同？层数代表什么区别？**
   * 单个界面的反射强弱由两层材料的**折射率比值 $n_H / n_L$** 决定（差得越大，单次反射越强）。
   * $N$ 对（即 $2N$ 层）高低折射率膜堆在中心波长处的峰值反射率为（空气 $n_0=1$、基底 $n_s$，顶层为高折射率）：
     $$R = \left(\frac{\dfrac{n_0}{n_s}\left(\dfrac{n_L}{n_H}\right)^{2N} - 1}{\dfrac{n_0}{n_s}\left(\dfrac{n_L}{n_H}\right)^{2N} + 1}\right)^2$$
   * **不同材料需要的对数差很远**（折射率差越大，层数越少）：
     * 例如介质膜 $\text{TiO}_2/\text{SiO}_2$（$n \approx 2.4 / 1.46$，差很大，基底 $n_s=1.5$）：$N=8$ 对反射率就到 $99.91\%$，$N=10$ 对高达 $99.987\%$；
     * 例如半导体外延膜 $\text{GaAs}/\text{AlAs}$（$n \approx 3.5 / 2.9$，差较小，基底 $n_s=3.5$）：需要 $N=20$ 对才到 $99.94\%$，$N=30$ 对才到 $99.999\%$。
   * **层数多 vs 少的区别**：层数越多 $\implies$ 反射率 $R$ 越逼近 $100\%$ $\implies$ 光子越难漏出、$Q$ 值越高；但也不是无限越多越好——层数太多除了生长耗时、膜层应力大、材料自身吸收损耗变大外，如果反射率太高，泵浦光进不去、信号光也漏不出来（探测不到），所以通常把**出光面那一侧的 DBR 故意少镀几对**。
3. **关键纠偏：腔层像光纤一样靠“高折射率芯包在低折射率里”吗？**
   * **不是！你联想到的是“平面波导”（压扁的光纤），它和 DBR 微腔的束缚机制完全不同：**
     * **光纤 / 平面波导**：光**平行于膜面**往前跑，靠的是**全反射（TIR）**，所以中间芯层的折射率**必须高于**包层。
     * **DBR 平面微腔**：光在上下两面 DBR 之间**垂直来回弹跳**，靠的是上下两面镜子的**布拉格干涉反射**，跟全反射没关系！
   * 因此，中间夹着的**腔层折射率既可以高，也可以低，甚至可以直接是空气**（两个 DBR 中间留一条空气缝）。
   * 至于腔层紧挨着的那一层放高折射率还是低折射率，决定的是**界面反射的相位**（光从低折射率撞高折射率有 $\pi$ 相移，产生波节；从高撞低无相移，产生波腹）。选哪一层挨着腔层，目的是让腔内驻波的**电场最强点（波腹）正好落在发光材料所在的高度**。

### 3. 哈密顿量（Hamiltonian）是什么？跟实验有什么关系？

* **本质是什么**：在经典力学里，$H = T + V$ 就是系统的**总能量**（动能 + 势能）。在量子力学和光学谐振体系里，系统有一组离散的模式，于是把 $H$ 写成一个**能量矩阵**：
  * **主对角线元素**（如 $E_1, E_2$）：代表如果没有相互作用，每个模式各自的“原生能量”（对应光谱仪里各自原本的峰位）；
  * **非对角线元素**（如 $g$）：代表两个模式之间互相交换能量的**耦合强度**。
* **为什么实验组会里天天出现它？它跟光谱仪测的数据怎么挂钩？**
  * 一句话：**你在实验台上拿光谱仪直接测到的峰位（把波长 $\lambda$ 换算成光子能量 $E = hc/\lambda$），就是哈密顿量矩阵 $H$ 的本征值！**
  * 看一个最简单的 $2\times 2$ 例子：假设系统里有两个原本能量为 $E_1, E_2$ 的模式，彼此耦合强度为 $g$，写下来就是：
    $$H = \begin{pmatrix} E_1 & g \\ g & E_2 \end{pmatrix}$$
    解矩阵特征方程 $\det(H - E I) = 0$，算出两个本征值：
    $$E_\pm = \frac{E_1 + E_2}{2} \pm \sqrt{\left(\frac{E_1 - E_2}{2}\right)^2 + g^2}$$
  * **对实验者的用途**：实验室里没有一把尺子能直接量出“耦合强度 $g$ 是多少”，但光谱仪能直接拍出分裂后的两条峰曲线 $E_+$ 和 $E_-$。把实验拍出来的曲线拿去和 $H$ 的本征值公式**拟合**，就能把隐藏在里面的物理参数（比如 $g$、失谐量、有效质量）反推出来。所以 $H$ 就是连接**物理模型**和**实验光谱图**的翻译器。

### 4. 什么是平面腔模？为什么反推公式长那样？为什么师姐的图是“带峰值的一元二次曲线”？

1. **什么是平面腔模？结构是什么？**
   * **结构**：就是一个极薄的“平板三明治”——上面一片平面 DBR 镜子、下面一片平面 DBR 镜子，中间夹一层厚度均匀为 $L$、有效折射率为 $n_{\text{eff}}$ 的平板介质（腔层）。
   * **平面腔模**：光在上下两面平行镜子之间反复弹跳，只有满足**竖直方向干涉相长（形成驻波）**的特定波长才能存活下来，这种允许存在的驻波就叫平面腔模。
2. **零跳跃推导 $\lambda(\theta)$（为什么斜着走波长反而短？）**
   * 腔内光的波矢大小为 $k = \dfrac{2\pi n_{\text{eff}}}{\lambda}$。把波矢按空间分解为**垂直镜面的分量 $k_z$** 和**平行镜面的分量 $k_\parallel$**。
   * **第 1 步（镜子锁死了 $k_z$）**：上下两面镜子只限制了竖直方向的高度 $L$，所以不管光斜着走还是直着走，竖直方向必须凑出整数个半波长，即 **$k_z = \dfrac{m\pi}{L}$ 是一个定死的常数**。
   * **第 2 步（正入射 vs 斜入射对比）**：
     * 正入射（$\theta = 0^\circ$）时没有水平分量，波矢全在竖直方向：$k_0 = \dfrac{2\pi n_{\text{eff}}}{\lambda_0} = k_z$；
     * 腔内以倾角 $\theta_{\text{in}}$ 斜着走时，竖直分量是斜边的投影：$k_z = k \cos\theta_{\text{in}} = \dfrac{2\pi n_{\text{eff}}}{\lambda(\theta)}\cos\theta_{\text{in}}$。
     * 因为 $k_z$ 始终相等，联立直接消去 $2\pi n_{\text{eff}}$：
       $$\frac{\cos\theta_{\text{in}}}{\lambda(\theta)} = \frac{1}{\lambda_0} \implies \lambda(\theta) = \lambda_0 \cos\theta_{\text{in}} = \lambda_0 \sqrt{1 - \sin^2\theta_{\text{in}}}$$
     * *直觉*：直角三角形里，竖直直角边 $k_z$ 被腔厚锁死了，光线一斜，斜边 $k$ 必然比直角边 $k_z$ 更长；而 $k \propto 1/\lambda$，波矢变大意味着波长 $\lambda$ 必须变短。
   * **第 3 步（换算到空气里物镜看到的角 $\theta$）**：光从腔里射出到空气（$n_{\text{air}}=1$）遵循高中折射定律：
     $$n_{\text{eff}} \sin\theta_{\text{in}} = 1 \cdot \sin\theta \implies \sin\theta_{\text{in}} = \frac{\sin\theta}{n_{\text{eff}}}$$
     代入第 2 步，立即得到：
     $$\lambda(\theta) = \lambda_0 \sqrt{1 - \left(\frac{\sin\theta}{n_{\text{eff}}}\right)^2}$$
3. **破案！为什么你觉得它该是单调斜率，而师姐的图上是“带峰值的一元二次曲线”？**
   * 你只看 $\theta \in [0^\circ, +44.4^\circ]$ 这一半时，它确实是一直往下掉的单调曲线。
   * **但物镜收集的是以光轴为中心、左右对称的一整只光锥！** 横坐标角度是从 **$-44.4^\circ$ 扫到 $0^\circ$ 再扫到 $+44.4^\circ$**。
   * 看公式里的 $\sin^2\theta$：它是**偶函数**（往左斜 $20^\circ$ 和往右斜 $20^\circ$ 波长完全相同）。在小角度下用近似 $\sqrt{1 - x} \approx 1 - x/2$ 展开：
     $$\lambda(\theta) \approx \lambda_0 - \frac{\lambda_0}{2 n_{\text{eff}}^2}\theta^2$$
   * **这正是一条以 $\theta = 0^\circ$ 为对称轴、开口向下的一元二次抛物线！**
     * 最高点（峰值）就在正中央 $\theta = 0^\circ$ 处，波长 $\lambda_0 = 690\text{ nm}$；
     * 往左到 $-44.4^\circ$、往右到 $+44.4^\circ$ 对称滑落，两端截止在 $631\text{ nm}$。
   * *(这也是老师要“反推实际 NA”的直接原因：只要光路后面有遮挡，这条开口向下的抛物线就会在左右两侧被提前“砍断”，截止点就够不到 $631\text{ nm}$。)*

### 6. 补齐断层：从波长 $\lambda$ 到焦距 $f$ 的完整三步推导

上一轮漏掉了最核心的**第 2 步（磨镜者公式）**，现在把三步完整接起来：

1. **第 1 步（材料色散：波长 $\lambda \to$ 玻璃折射率 $n$）**
   * 普通光学玻璃对不同波长的光折射率不同，波长越短、折射率越大（正常色散，比如高中三棱镜里蓝光比红光弯得更厉害，经验上可用柯西公式 $n(\lambda) = A + B/\lambda^2$ 描述）。因此：
     $$n(631\text{ nm}) > n(690\text{ nm})$$
2. **第 2 步（磨镜者公式 Lensmaker's equation：折射率 $n \to$ 焦距 $f$）**
   * 一片磨好的薄透镜，前后两面的球面曲率半径 $R_1, R_2$ 是固定不变的几何常数（对凸透镜，$\frac{1}{R_1} - \frac{1}{R_2} > 0$）。它的焦距 $f$ 由材料折射率 $n$ 决定：
     $$\frac{1}{f(\lambda)} = \bigl(n(\lambda) - 1\bigr)\left(\frac{1}{R_1} - \frac{1}{R_2}\right)$$
   * 盯着等式看：右边括号是固定正数，$n(631\text{ nm}) > n(690\text{ nm})$ 直接导致 $n - 1$ 更大 $\implies \dfrac{1}{f}$ 更大 $\implies$ 取倒数后焦距更短：
     $$f(631\text{ nm}) < f(690\text{ nm})$$
   * *直觉*：短波被玻璃拐弯折得更狠，平行光穿过透镜后更早交汇到光轴上，焦点自然离透镜更近。
3. **第 3 步（高斯成像公式：焦距 $f \to$ 像距 $v$）**
   * 在刚才的 4f 光路里，镜片摆在台面上不动，物距 $u$ 对所有颜色都一样。代入高斯公式 $\dfrac{1}{u} + \dfrac{1}{v} = \dfrac{1}{f(\lambda)}$，改写成：
     $$\frac{1}{v(\lambda)} = \frac{1}{f(\lambda)} - \frac{1}{u}$$
   * 因为 $f(631) < f(690) \implies \dfrac{1}{f(631)} > \dfrac{1}{f(690)}$，减掉相同的 $\dfrac{1}{u}$ 后仍有 $\dfrac{1}{v(631)} > \dfrac{1}{v(690)}$，取倒数得 **$v(631\text{ nm}) < v(690\text{ nm})$**。
   * **后果**：631 nm 的清晰像结在狭缝前面，690 nm 的清晰像结在狭缝上——两头没法同时清晰，这就是为什么跨越 631–690 nm 时需要换成**消色差双胶合透镜**（用两种不同色散特性的玻璃一正一负抵消，把 $f(631)$ 和 $f(690)$ 重新拉平）。

## 一、高频词的统一因果链（精简映射）

### 1. 光学腔的“牢笼”与“放大器”
* **DBR（Distributed Bragg Reflector，分布式布拉格反射镜）**：用高、低折射率介质交替镀膜，每层光学厚度严格等于目标中心波长的 $\lambda/(4n)$，靠多界面反射相干相长形成高反带（Stopband）。两片 DBR 面对面夹一个腔层，就构成高反射率平面微腔（Fabry-Pérot cavity）。**实验盲区**：DBR 只在有限带宽内高反，带边反射率会陡降，短波或大角度处容易出现截断。
* **高 Q 值（Quality Factor）**：$Q = \dfrac{\omega_0}{\Delta\omega} = \omega_0 \tau_c$。物理上衡量**光子在腔里被锁住的平均寿命 $\tau_c$ 有多长**；光谱上直接表现为腔模线宽 $\Delta\lambda$ 极窄，光子能量损耗极低，才容易达到激光或凝聚阈值。
* **局域场（Local Field）**：把光子能量压缩到极小的有效模式体积 $V_{\text{eff}}$ 内。电场能量密度暴增后，既能通过 Purcell 效应加速自发辐射，也能把光与物质的耦合强度 $g \propto 1/\sqrt{V_{\text{eff}}}$ 拉高，是进强耦合区和降阈值激光的关键。

### 2. 激发源、激子 BEC、激光判据与非厄米模型
* **超快（Ultrafast）**：指脉宽在飞秒（fs, $10^{-15}\text{ s}$）到皮秒（ps, $10^{-12}\text{ s}$）量级的脉冲激光。实验上用它主要图两件事：① 极短时间内集中能量，**峰值功率极高而平均热负载低**，能在不烧毁样品的前提下打过阈值；② 配合泵浦-探测（pump-probe）或条纹相机做时间分辨测量，直接看 ps 尺度的激子形成、弛豫与退相干动力学。
* **激发激子（Exciton）与玻色-爱因斯坦凝聚（BEC）**：半导体吸光后，电子跃迁到导带并与价带留下的空穴靠库仑力束缚成电中性的准粒子，就是**激子**（整数自旋，属于玻色子）。激子本身较重，单独做 BEC 往往需要极低温度；但如果把它放进高 Q 微腔并与腔光子发生**强耦合**，会杂化成新准粒子**激子极化激元（Exciton-Polariton）**。它的有效质量极轻（比电子轻几个数量级），因此在液氦甚至室温下就能发生宏观占据基态（$k_\parallel = 0$）的 **BEC**——实验中常称**极化激元激光（Polariton Lasing，无需粒子数反转）**，这与传统半导体的弱耦合**光子激光（Photon Lasing，需粒子数反转）**有本质区别。
* **判断激光生成的条件（组会最易踩雷点）**：**“出现一个单峰”绝对不等于出了激光！** 即使只是普通自发辐射被高 Q 腔模过滤，光谱上也会出现一个尖锐单峰。实验室判定出光（无论是光子激光还是极化激元 BEC）必须交叉核查四件事：
  1. **输入-输出阈值拐点**：出射光强随泵浦功率呈非线性陡增（双对数坐标下的“S 型曲线”）；
  2. **线宽突变变窄**：跨过阈值时半高全宽（FWHM）急剧压缩；
  3. **相干性建立**：空间干涉可见度（$g^{(1)}$）突增，或二阶光子关联 $g^{(2)}(0) \to 1$；
  4. **峰位与动量演化**：极化激元 BEC 会在 $k_\parallel=0$ 处宏观集聚并随密度发生持续**蓝移**；若功率继续加大导致激子离解、蓝移直接跳回裸腔模且阈值再拐一次，那是退化成了第二阈值的传统光子激光。
* **哈密顿量（$H$）与非厄米哈密顿量（Non-Hermitian $H$）**：
  * 教材里的封闭无损系统满足厄米性 $H^\dagger = H$，解出的本征能量全是实数，总能量守恒。
  * 但你们的微腔和激子体系必然是**开放系统**：一方面有外界超快泵浦注入**增益**（等效写成虚部 $+i\gamma_{\text{gain}}$），另一方面光子从 DBR 漏出供你探测、激子也会非辐射复合带来**损耗**（等效写成虚部 $-i\gamma_{\text{loss}}$）。把这种“双向耦合 + 各自的增益/损耗虚部”写进矩阵后，$H^\dagger \neq H$，就是**非厄米哈密顿量**。它的本征值变成复数：实部决定共振波长/能级劈裂，虚部正负决定模式是衰减还是起振；当参数调到实部与虚部同时简并时，还会出现**奇异点（Exceptional Point, EP）**，用来研究拓扑激光或超灵敏传感。

## 二、重点拆解：631–690 nm、$\text{NA}=0.7$ 反推实际 NA 与“消色差光路”

> **前提声明（未验证项）**：因为我没看到原图，所以以下先以最常见的**“平面微腔角分辨色散（或从正入射到最大角度的单支腔模范围）”**来推演因果链，并在最后指出如果图不是角分辨谱时会发生什么偏差，这需要你回组核实原图坐标轴。

### 1. 先验算师姐的数字，再看导师为什么反驳
1. **$\theta = 44.4^\circ$ 怎么算的**：物镜在空气（$n=1$）中使用时，数值孔径定义 $\text{NA} = n\sin\theta_{\max}$。代入 $\text{NA}=0.7$，精确解得：
   $$\theta_{\max} = \arcsin(0.7) = 44.4270^\circ \approx 44.4^\circ$$
2. **师姐和导师的核心分歧在哪**：
   * 师姐大概率是直接读取了物镜筒壁上刻的**标称 $\text{NA} = 0.7$**，认为物镜既然能收集 $\pm 44.4^\circ$ 锥角内的光，那么图上覆盖的范围就对应 $0^\circ \to 44.4^\circ$，“所以是对的”。
   * **但导师抓住了实验光学的铁律：物镜的标称 NA $\neq$ 整套光路实际传到光谱仪的有效 $\text{NA}_{\text{actual}}$！** 只要物镜后面的中继透镜口径不够、反射镜或狭缝边缘切掉了大角度光线（渐晕/Vignetting），或者光路存在严重**色差**导致短波端虚焦溢光，最终能进光谱仪的最大发射角 $\theta_{\text{actual}}$ 就会**小于** $44.4^\circ$。
3. **如何从波长反推“实际 NA”？（以平面腔模为例）**：
   * 对于有效折射率为 $n_{\text{eff}}$ 的平面 Fabry-Pérot 微腔，斜入射时面内波矢守恒，腔内纵模共振波长随空气外发射角 $\theta$ 发生蓝移：
     $$\lambda(\theta) = \lambda_0 \sqrt{1 - \left(\frac{\sin\theta}{n_{\text{eff}}}\right)^2}$$
   * 把你听到的两个数字 $\lambda_0 = 690\text{ nm}$（假设对应 $\theta=0^\circ$ 正入射底端）和 $\lambda_{\min} = 631\text{ nm}$（假设对应最大采集角边缘）代入验算：
     $$\sqrt{1 - \left(\frac{631}{690}\right)^2} = 0.40460$$
   * 若按师姐的 $\sin\theta_{\max}=0.7$，可倒算出腔的等效折射率需为 $n_{\text{eff}} = 0.7 / 0.40460 = 1.7301$（这在高分子/钙钛矿/氧化物混合微腔中属于合理量级）。反过来，如果材料/腔结构的 $n_{\text{eff}}$ 已知，导师就可以通过光谱最蓝端的截止波长 $\lambda_{\min}$ 直接求解系统**实际收集到的 NA**：
     $$\text{NA}_{\text{actual}} = \sin\theta_{\text{actual}} = n_{\text{eff}} \sqrt{1 - \left(\frac{\lambda_{\min}}{\lambda_0}\right)^2}$$
   * **这一步极易踩的三个失效边界（别盲套公式！）**：
     1. **欠定陷阱**：如果 $n_{\text{eff}}$ 自身也未知，只凭 631 nm 和 690 nm 两个端点数，方程是**欠定**的（无法同时解出 $n_{\text{eff}}$ 和 $\text{NA}_{\text{actual}}$），必须整条 $\lambda(\theta)$ 抛物线做双参数拟合或已知腔结构；
     2. **强耦合偏离**：如果样本处于激子强耦合区，测到的是下极化激元支（LPB）而非纯光子腔模，大角度处色散会被激子能级“压平”（反交叉），硬套纯腔模公式反推 $\text{NA}_{\text{actual}}$ 会产生系统误差；
     3. **非色散截断**：大角度（接近 $44.4^\circ$）下还会出现 TE/TM 偏振劈裂，且 631 nm 也可能是 DBR 高反带边缘反射率掉光造成的截断，而不是孔径角截断。

### 2. 为什么紧接着必须讲“消色差的光路”？
你从 631 nm 到 690 nm 光信号本身就跨了近 $60\text{ nm}$；如果再加上短波激发激光（如 400 nm 或 532 nm，需核实），整条光路跨越上百纳米。回顾你第 1 次笔记学的高斯公式 $\dfrac{1}{u}+\dfrac{1}{v}=\dfrac{1}{f}$：普通单透镜（如 N-BK7 平凸镜）的玻璃折射率随波长变化（$n_{\text{蓝}} > n_{\text{红}}$），导致**短波焦距更短、长波焦距更长**，即 $f(631\text{ nm}) < f(690\text{ nm})$。

在这类角分辨/微腔光路里，不消色差会直接引发两处致命故障：
1. **破坏后焦面（BFP，$k$ 空间）的 4f 成像与实际 NA**：
   * 实验室测角分辨色散，通常用一套 **4f 中继透镜**把物镜的**后焦面（Back Focal Plane, BFP）**成像到光谱仪狭缝上。在后焦面上，离光轴半径满足阿贝正弦条件 $r = f_{\text{obj}}\sin\theta$（不同半径直接代表不同出射角/动量）。
   * 若中继透镜不消色差，631 nm 的后焦面像会落在狭缝**前方**，690 nm 的像落在狭缝**后方**（轴向色差），导致你只能对准其中某个波长聚焦，另一端在狭缝上发虚——不仅角度分辨率变糊，而且高角度光线经过不同焦距的放大率偏移与狭缝/镜框遮挡后，**不同波长对应到的实际有效 NA 都不一样**！
2. **激发与收集失配（非共焦）**：
   * 如果激发光和收集荧光共用透镜，绿光/蓝光聚焦的位置和红光聚焦的位置沿光轴错开几百微米到几毫米，样品表面同时处于“激子没聚焦”或“发射光没收进狭缝”的尴尬状态，局域激发效率大幅下降。

**工程上怎么解决（按成本与代价排序）**：
| 方案 | 原理 | 优点 | 实验代价 / 限制 |
|---|---|---|---|
| **消色差双胶合透镜 (Achromatic Doublet)** | 用高色散火石玻璃与低色散冕牌玻璃胶合，让两个设计波长的焦距重合 | 价格适中、共轴好装调，4f 中继最常用 | 胶合层耐强脉冲功率有限；离轴大视场仍有像差；超快飞秒脉冲会引入材料群速度色散（脉宽展宽） |
| **复消色差物镜 (Apochromat)** | 多组特殊色散玻璃校正三波长色差与球差 | 从激发到宽谱收集同时共焦 | 极贵，通光孔径、工作距离受限 |
| **离轴抛物面镜 (OAP, 全反射)** | 利用反射定律（反射角不依赖波长）实现**零色差**、零脉冲展宽 | 跨几百纳米宽谱与飞秒超快最理想 | **对准噩梦**：反射面无轴对称性，俯仰/偏摆/平移稍微歪一点就引入巨大彗差与像散 |

## 三、导师派给你的任务：“摩尔转角”（更正：**莫尔转角 / Moiré Twist Angle**）

1. **先纠词**：实验物理和光子学里标准叫法是 **莫尔转角（Moiré twist angle）**（源自法语 *Moiré*，大概率是语音/笔记同音误记为“摩尔”）。生活里两层纱窗稍微错开一个角度叠加，会出现比网格粗得多的大条纹，这就是**莫尔超晶格（Moiré superlattice）**。
2. **核心几何公式（必记）**：两层晶格常数均为 $a$ 的二维周期结构，以小角度 $\theta$ 相对旋转堆叠时，产生的新超晶格周期 $a_M$ 为：
   $$a_M = \frac{a}{2\sin(\theta/2)} \approx \frac{a}{\theta}\quad (\text{小角度下 } \theta \text{ 取弧度})$$
   例如当 $\theta = 1^\circ = 0.0175\text{ rad}$ 时，$a_M / a = 57.30$——周期直接放大了 57 倍！
3. **为什么扭转一个角度就能出这么多新物理？**
   * **平带（Flat Band）与慢光效应**：实空间周期暴涨 $\implies$ 倒易（动量/$k$）空间布里渊区剧烈缩小，原本倾斜的能带被反复折叠成密集的子带；当层间耦合强度与周期缩放达成某种平衡（即所谓的“魔角”附近）时，某条能带会被压得几乎水平（**平带**）。因为群速度 $v_g = \dfrac{1}{\hbar}\dfrac{dE}{dk} \to 0$，光或激子几乎“定在原地”，停驻时间与态密度激增！
   * **莫尔局域势阱**：在一个莫尔超胞内部，有的区域两层原子/微结构对齐（AA 堆垛），有的错位（AB 堆垛），导致局部折射率或能隙呈周期性起伏，天然形成**阵列式纳米势阱/局域光场**，把激子或光子锁在势阱里，极大降低激光/BEC 阈值。
4. **回组必须向师姐确认的两种可能体系（目前未验证）**：
   * **路径 A（二维材料莫尔激子 / 莫尔极化激元）**：比如把两层单层过渡金属硫族化合物（TMDs，其激子发射多在红光–近红外波段）按特定转角贴在一起形成莫尔激子势阱，再放进 DBR 微腔做强耦合极化激元与 BEC；
   * **路径 B（莫尔光子晶体 / 扭转微腔）**：直接通过微纳加工把两层周期光子晶体板（或光栅）转一个 $\theta$ 叠合，不做任何电子激子耦合也能仅靠光子平带产生极高 Q 值局域模与低阈值激光（甚至结合增益损耗做非厄米莫尔拓扑激光）。

> **如何高效完成导师的作业？** 先去要组里师姐正在做或组会提到的 1–2 篇核心文献，只带着三个锚点去读：① 你们扭转的“两层”究竟是**二维半导体**还是**光子晶体微结构**？② 研究的转角大约在**几度**（对应多大的 $a_M$）？③ 光谱测量是不是就靠那套**消色差角分辨光路**看动量空间的平带色散？

## 3. 消色差光路（接上文）

**解法**：
- **消色差双胶合透镜**：一片冕牌玻璃正透镜（色散小）加一片火石玻璃负透镜（色散大）。设计条件是

  $$\frac{\phi_1}{V_1} + \frac{\phi_2}{V_2} = 0$$

  其中 φ 是光焦度，V 是阿贝数（数值越大，色散越小）。满足这个条件，两个波长（通常取 F 线和 C 线）的焦点就会重合。总光焦度 φ₁+φ₂ 不为零，所以透镜仍然能成像。
- **复消色差（APO）**：让三个波长的焦点重合，用于宽带成像。
- **反射式光路**：用离轴抛物面镜等反射元件代替透镜。反射角与波长无关，从原理上就没有色差，代价是不好调。

**为什么组里在意**：角分辨光谱依靠"后焦面上的位置 ↔ 出射角"这一一一对应关系。如果 631 nm 和 690 nm 的后焦面位置不同，同一角度在不同波长下会落在不同位置，色散图就会被拉歪，反推出的 NA 也就不准。

一条典型的傅里叶成像链路：

```
样品 → 物镜(NA 0.7) → 后焦面 → 透镜L1 → 透镜L2(把后焦面成像到光谱仪狭缝) → 光谱仪 + CCD
```

L1 和 L2 都应选消色差双胶合透镜，**而且要冕牌那一面朝向平行光**，这样球差最小。

## 4. 莫尔转角：建议的学习顺序

1. **几何**：两套周期为 a 的晶格相对转 θ，莫尔周期 $a_M \approx a/(2\sin(\theta/2)) \approx a/\theta$。用 Python 画两套六角点阵叠加，亲眼看看图案（30 分钟就能完成）。

## 2. NA = 0.7 → θ = 44.4° 是怎么回事

$$\sin\theta_{max} = NA = 0.7 \;\Rightarrow\; \theta_{max} = \arcsin 0.7 = 44.4^\circ$$

这是**角分辨光谱（傅里叶成像）**：物镜后焦面上的每个点对应一个出射角，所以图上的横轴是角度，也就是面内波矢

$$k_\parallel = \frac{2\pi}{\lambda}\sin\theta$$

你看到的 631–690 nm 的图应该就是**色散图**（波长对角度）。物镜能收集到的最大角度由 NA 决定，色散曲线在图上的截止边缘就对应 44.4°。老师的思路是**反过来用**：从截止处的波长和 k 读出实际的 sinθ_max，也就是实际 NA，再和标称值 0.7 对照，以此检验光路有没有用满 NA。
