## 一、高频词的统一因果链（精简映射）

### 1. 光学腔的“牢笼”与“放大器”
* **DBR（Distributed Bragg Reflector，分布式布拉格反射镜）**：用高、低折射率介质交替镀膜，每层光学厚度严格等于目标中心波长的 $\lambda/(4n)$，靠多界面反射相干相长形成高反带（Stopband）。两片 DBR 面对面夹一个腔层，就构成高反射率平面微腔（Fabry-Pérot cavity）。**实验盲区**：DBR 只在有限带宽内高反，带边反射率会陡降，短波或大角度处容易出现截断。
* **高 Q 值（Quality Factor）**：$Q = \dfrac{\omega_0}{\Delta\omega} = \omega_0 \tau_c$。物理上衡量**光子在腔里被锁住的平均寿命 $\tau_c$ 有多长**；光谱上直接表现为腔模线宽 $\Delta\lambda$ 极窄，光子能量损耗极低，才容易达到激光或凝聚阈值。
* **局域场（Local Field）**：把光子能量压缩到极小的有效模式体积 $V_{\text{eff}}$ 内。电场能量密度暴增后，既能通过 Purcell 效应加速自发辐射，也能把光与物质的耦合强度 $g \propto 1/\sqrt{V_{\text{eff}}}$ 拉高，是进强耦合区和降阈值激光的关键。

### 2. 激发源、激子 BEC、激光判据与非厄米模型
* **超快（Ultrafast）**：指脉宽在飞秒（fs, $10^{-15}\text{ s}$）到皮秒（ps, $10^{-12}\text{ s}$）量级的脉冲激光。实验上用它主要图两件事：① 极短时间内集中能量，**峰值功率极高而平均热负载低**，能在不烧毁样品的前提下打过阈值；② 配合泵浦-探测（pump-probe）或条纹相机做时间分辨测量，直接看 ps 尺度的激子形成、弛豫与退相干动力学。
* **激发激子（Exciton）与玻色-爱因斯坦凝聚（BEC）**：半导体吸光后，电子跃迁到导带并与价带留下的空穴靠库仑力束缚成电中性的准粒子，就是**激子**（整数自旋，属于玻色子）。激子本身较重，单独做 BEC 往往需要极低温度；但如果把它放进高 Q 微腔并与腔光子发生**强耦合**，会杂化成新准粒子**激子极化激元（Exciton-Polariton）**。它的有效质量极轻（比电子轻几个数量级），因此在液氦甚至室温下就能发生宏观占据基态（$k_\parallel = 0$）的 **BEC**——实验中常称**极化激元激光（Polariton Lasing，无需粒子数反转）**，这与传统半导体的弱耦合**光子激光（Photon Lasing，需粒子数反转）**有本质区别。
* **判断激光生成的条件（组会最易踩雷点）**：**“出现一个单峰”绝对不等于出了激光！** 即使只是普通自发辐射被高 Q 腔模过滤，光谱上也会出现一个尖锐单峰。实验室判定出光（无论是光子激光还是极化激元 BEC）必须交叉核查四件事：
  1. **输入-输出阈值拐点**：出射光强随泵浦功率呈非线性陡增（双对数坐标下的“S 型曲线”）；
  2. **线宽突变变窄**：跨过阈值时半高全宽（FWHM）急剧压缩；
  3. **相干性建立**：空间干涉可见度（$g^{(1)}$）突增，或二阶光子关联 $g^{(2)}(0) \to 1$；
  4. **峰位与动量演化**：极化激元 BEC 会在 $k_\parallel=0$ 处宏观集聚并随密度发生持续**蓝移**；若功率继续加大导致激子离解、蓝移直接跳回裸腔模且阈值再拐一次，那是退化成了第二阈值的传统光子激光。
* **哈密顿量（$H$）与非厄米哈密顿量（Non-Hermitian $H$）**：
  * 教材里的封闭无损系统满足厄米性 $H^\dagger = H$，解出的本征能量全是实数，总能量守恒。
  * 但你们的微腔和激子体系必然是**开放系统**：一方面有外界超快泵浦注入**增益**（等效写成虚部 $+i\gamma_{\text{gain}}$），另一方面光子从 DBR 漏出供你探测、激子也会非辐射复合带来**损耗**（等效写成虚部 $-i\gamma_{\text{loss}}$）。把这种“双向耦合 + 各自的增益/损耗虚部”写进矩阵后，$H^\dagger \neq H$，就是**非厄米哈密顿量**。它的本征值变成复数：实部决定共振波长/能级劈裂，虚部正负决定模式是衰减还是起振；当参数调到实部与虚部同时简并时，还会出现**奇异点（Exceptional Point, EP）**，用来研究拓扑激光或超灵敏传感。

## 二、重点拆解：631–690 nm、$\text{NA}=0.7$ 反推实际 NA 与“消色差光路”

> **前提声明（未验证项）**：因为我没看到原图，所以以下先以最常见的**“平面微腔角分辨色散（或从正入射到最大角度的单支腔模范围）”**来推演因果链，并在最后指出如果图不是角分辨谱时会发生什么偏差，这需要你回组核实原图坐标轴。

### 1. 先验算师姐的数字，再看导师为什么反驳
1. **$\theta = 44.4^\circ$ 怎么算的**：物镜在空气（$n=1$）中使用时，数值孔径定义 $\text{NA} = n\sin\theta_{\max}$。代入 $\text{NA}=0.7$，精确解得：
   $$\theta_{\max} = \arcsin(0.7) = 44.4270^\circ \approx 44.4^\circ$$
2. **师姐和导师的核心分歧在哪**：
   * 师姐大概率是直接读取了物镜筒壁上刻的**标称 $\text{NA} = 0.7$**，认为物镜既然能收集 $\pm 44.4^\circ$ 锥角内的光，那么图上覆盖的范围就对应 $0^\circ \to 44.4^\circ$，“所以是对的”。
   * **但导师抓住了实验光学的铁律：物镜的标称 NA $\neq$ 整套光路实际传到光谱仪的有效 $\text{NA}_{\text{actual}}$！** 只要物镜后面的中继透镜口径不够、反射镜或狭缝边缘切掉了大角度光线（渐晕/Vignetting），或者光路存在严重**色差**导致短波端虚焦溢光，最终能进光谱仪的最大发射角 $\theta_{\text{actual}}$ 就会**小于** $44.4^\circ$。
3. **如何从波长反推“实际 NA”？（以平面腔模为例）**：
   * 对于有效折射率为 $n_{\text{eff}}$ 的平面 Fabry-Pérot 微腔，斜入射时面内波矢守恒，腔内纵模共振波长随空气外发射角 $\theta$ 发生蓝移：
     $$\lambda(\theta) = \lambda_0 \sqrt{1 - \left(\frac{\sin\theta}{n_{\text{eff}}}\right)^2}$$
   * 把你听到的两个数字 $\lambda_0 = 690\text{ nm}$（假设对应 $\theta=0^\circ$ 正入射底端）和 $\lambda_{\min} = 631\text{ nm}$（假设对应最大采集角边缘）代入验算：
     $$\sqrt{1 - \left(\frac{631}{690}\right)^2} = 0.40460$$
   * 若按师姐的 $\sin\theta_{\max}=0.7$，可倒算出腔的等效折射率需为 $n_{\text{eff}} = 0.7 / 0.40460 = 1.7301$（这在高分子/钙钛矿/氧化物混合微腔中属于合理量级）。反过来，如果材料/腔结构的 $n_{\text{eff}}$ 已知，导师就可以通过光谱最蓝端的截止波长 $\lambda_{\min}$ 直接求解系统**实际收集到的 NA**：
     $$\text{NA}_{\text{actual}} = \sin\theta_{\text{actual}} = n_{\text{eff}} \sqrt{1 - \left(\frac{\lambda_{\min}}{\lambda_0}\right)^2}$$
   * **这一步极易踩的三个失效边界（别盲套公式！）**：
     1. **欠定陷阱**：如果 $n_{\text{eff}}$ 自身也未知，只凭 631 nm 和 690 nm 两个端点数，方程是**欠定**的（无法同时解出 $n_{\text{eff}}$ 和 $\text{NA}_{\text{actual}}$），必须整条 $\lambda(\theta)$ 抛物线做双参数拟合或已知腔结构；
     2. **强耦合偏离**：如果样本处于激子强耦合区，测到的是下极化激元支（LPB）而非纯光子腔模，大角度处色散会被激子能级“压平”（反交叉），硬套纯腔模公式反推 $\text{NA}_{\text{actual}}$ 会产生系统误差；
     3. **非色散截断**：大角度（接近 $44.4^\circ$）下还会出现 TE/TM 偏振劈裂，且 631 nm 也可能是 DBR 高反带边缘反射率掉光造成的截断，而不是孔径角截断。

### 2. 为什么紧接着必须讲“消色差的光路”？
你从 631 nm 到 690 nm 光信号本身就跨了近 $60\text{ nm}$；如果再加上短波激发激光（如 400 nm 或 532 nm，需核实），整条光路跨越上百纳米。回顾你第 1 次笔记学的高斯公式 $\dfrac{1}{u}+\dfrac{1}{v}=\dfrac{1}{f}$：普通单透镜（如 N-BK7 平凸镜）的玻璃折射率随波长变化（$n_{\text{蓝}} > n_{\text{红}}$），导致**短波焦距更短、长波焦距更长**，即 $f(631\text{ nm}) < f(690\text{ nm})$。

在这类角分辨/微腔光路里，不消色差会直接引发两处致命故障：
1. **破坏后焦面（BFP，$k$ 空间）的 4f 成像与实际 NA**：
   * 实验室测角分辨色散，通常用一套 **4f 中继透镜**把物镜的**后焦面（Back Focal Plane, BFP）**成像到光谱仪狭缝上。在后焦面上，离光轴半径满足阿贝正弦条件 $r = f_{\text{obj}}\sin\theta$（不同半径直接代表不同出射角/动量）。
   * 若中继透镜不消色差，631 nm 的后焦面像会落在狭缝**前方**，690 nm 的像落在狭缝**后方**（轴向色差），导致你只能对准其中某个波长聚焦，另一端在狭缝上发虚——不仅角度分辨率变糊，而且高角度光线经过不同焦距的放大率偏移与狭缝/镜框遮挡后，**不同波长对应到的实际有效 NA 都不一样**！
2. **激发与收集失配（非共焦）**：
   * 如果激发光和收集荧光共用透镜，绿光/蓝光聚焦的位置和红光聚焦的位置沿光轴错开几百微米到几毫米，样品表面同时处于“激子没聚焦”或“发射光没收进狭缝”的尴尬状态，局域激发效率大幅下降。

**工程上怎么解决（按成本与代价排序）**：

|---|---|---|---|

## 三、导师派给你的任务：“摩尔转角”（更正：**莫尔转角 / Moiré Twist Angle**）

1. **先纠词**：实验物理和光子学里标准叫法是 **莫尔转角（Moiré twist angle）**（源自法语 *Moiré*，大概率是语音/笔记同音误记为“摩尔”）。生活里两层纱窗稍微错开一个角度叠加，会出现比网格粗得多的大条纹，这就是**莫尔超晶格（Moiré superlattice）**。
2. **核心几何公式（必记）**：两层晶格常数均为 $a$ 的二维周期结构，以小角度 $\theta$ 相对旋转堆叠时，产生的新超晶格周期 $a_M$ 为：
   $$a_M = \frac{a}{2\sin(\theta/2)} \approx \frac{a}{\theta}\quad (\text{小角度下 } \theta \text{ 取弧度})$$
   例如当 $\theta = 1^\circ = 0.0175\text{ rad}$ 时，$a_M / a = 57.30$——周期直接放大了 57 倍！
3. **为什么扭转一个角度就能出这么多新物理？**
   * **平带（Flat Band）与慢光效应**：实空间周期暴涨 $\implies$ 倒易（动量/$k$）空间布里渊区剧烈缩小，原本倾斜的能带被反复折叠成密集的子带；当层间耦合强度与周期缩放达成某种平衡（即所谓的“魔角”附近）时，某条能带会被压得几乎水平（**平带**）。因为群速度 $v_g = \dfrac{1}{\hbar}\dfrac{dE}{dk} \to 0$，光或激子几乎“定在原地”，停驻时间与态密度激增！
   * **莫尔局域势阱**：在一个莫尔超胞内部，有的区域两层原子/微结构对齐（AA 堆垛），有的错位（AB 堆垛），导致局部折射率或能隙呈周期性起伏，天然形成**阵列式纳米势阱/局域光场**，把激子或光子锁在势阱里，极大降低激光/BEC 阈值。
4. **回组必须向师姐确认的两种可能体系（目前未验证）**：
   * **路径 A（二维材料莫尔激子 / 莫尔极化激元）**：比如把两层单层过渡金属硫族化合物（TMDs，其激子发射多在红光–近红外波段）按特定转角贴在一起形成莫尔激子势阱，再放进 DBR 微腔做强耦合极化激元与 BEC；
   * **路径 B（莫尔光子晶体 / 扭转微腔）**：直接通过微纳加工把两层周期光子晶体板（或光栅）转一个 $\theta$ 叠合，不做任何电子激子耦合也能仅靠光子平带产生极高 Q 值局域模与低阈值激光（甚至结合增益损耗做非厄米莫尔拓扑激光）。

## 3. 消色差光路（接上文）

**解法**：
- **消色差双胶合透镜**：一片冕牌玻璃正透镜（色散小）加一片火石玻璃负透镜（色散大）。设计条件是

  $$\frac{\phi_1}{V_1} + \frac{\phi_2}{V_2} = 0$$

  其中 φ 是光焦度，V 是阿贝数（数值越大，色散越小）。满足这个条件，两个波长（通常取 F 线和 C 线）的焦点就会重合。总光焦度 φ₁+φ₂ 不为零，所以透镜仍然能成像。
- **复消色差（APO）**：让三个波长的焦点重合，用于宽带成像。
- **反射式光路**：用离轴抛物面镜等反射元件代替透镜。反射角与波长无关，从原理上就没有色差，代价是不好调。

**为什么组里在意**：角分辨光谱依靠"后焦面上的位置 ↔ 出射角"这一一一对应关系。如果 631 nm 和 690 nm 的后焦面位置不同，同一角度在不同波长下会落在不同位置，色散图就会被拉歪，反推出的 NA 也就不准。

一条典型的傅里叶成像链路：

```
样品 → 物镜(NA 0.7) → 后焦面 → 透镜L1 → 透镜L2(把后焦面成像到光谱仪狭缝) → 光谱仪 + CCD
```

L1 和 L2 都应选消色差双胶合透镜，**而且要冕牌那一面朝向平行光**，这样球差最小。

## 4. 莫尔转角：建议的学习顺序

1. **几何**：两套周期为 a 的晶格相对转 θ，莫尔周期 $a_M \approx a/(2\sin(\theta/2)) \approx a/\theta$。用 Python 画两套六角点阵叠加，亲眼看看图案（30 分钟就能完成）。
2. **魔角石墨烯**：θ ≈ 1.1° 时能带变平，出现超导。这是这个领域的起点，可以读 Cao et al., *Nature* 556, 43 (2018)。

| **摩尔转角** | 应为 **moiré twist angle**（莫尔/摩尔转角）。两层周期结构扭一个小角 θ，叠出周期大得多的莫尔超晶格，周期 ≈ a/θ | 用转角来调控激子或光子的能带，是当前的热点方向 |

**判断激光产生的条件**（组会上常用的三个判据，要同时满足）：
1. 输出强度对泵浦功率的曲线出现**阈值拐点**（双对数坐标下呈 S 形）；
2. 过阈值后**线宽突然变窄**；
3. 出现**相干性**：用干涉测一阶相干 g⁽¹⁾，或用 HBT 测 g⁽²⁾→1。

极化激元凝聚和普通激光的区别在于：前者不需要粒子数反转，阈值更低，而且能量随密度会发生**蓝移**。

## 2. NA = 0.7 → θ = 44.4° 是怎么回事

$$\sin\theta_{max} = NA = 0.7 \;\Rightarrow\; \theta_{max} = \arcsin 0.7 = 44.4^\circ$$

这是**角分辨光谱（傅里叶成像）**：物镜后焦面上的每个点对应一个出射角，所以图上的横轴是角度，也就是面内波矢

$$k_\parallel = \frac{2\pi}{\lambda}\sin\theta$$

你看到的 631–690 nm 的图应该就是**色散图**（波长对角度）。物镜能收集到的最大角度由 NA 决定，色散曲线在图上的截止边缘就对应 44.4°。老师的思路是**反过来用**：从截止处的波长和 k 读出实际的 sinθ_max，也就是实际 NA，再和标称值 0.7 对照，以此检验光路有没有用满 NA。
