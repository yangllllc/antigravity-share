  - `SKILL.md` 本身很克制（91 行 / ~9.9 KB），背后挂着 **211 份精选实战指南**（覆盖 **269 项现代 Web 特性**，分 17 类：CSS 18 / UI 行为 40 / UI 组件 23 / 性能 26 / 视觉设计 22 / 表单 19 / 安全 17 / HTML 8 / JS 6 / 浏览器内置 AI 5 / 无障碍 4 / WebMCP 3 等）。
  - 写法直击痛点：比如抽屉菜单直接用原生 `<dialog>` + `showModal()` + CSS `scroll-snap` + 滚动驱动动画，免写手势 JS 且自带键盘 Escape、焦点恢复与屏幕阅读器无障碍；并且每份指南都附带 **Baseline 浏览器兼容边界**、隐藏平台坑点（如 `fetchLater` 的 64KB 限制）和 **<50 行轻量级降级方案（Fallback）**。
  - **用 E2E 实测反向裁剪废话**：谷歌用 Playwright 在真实浏览器上跑了 229 个前端任务 / 1,955 条断言，**把模型裸跑就会的常识全删掉**，只留真正提分的部分。官方实测在 **Antigravity CLI（Gemini 4）** 上，裸跑通过率 56% → 用它之后 **97%（+41 个百分点）**（Claude Opus 5.5：54% → 94%；Codex GPT-6.1 Sol：49% → 85%）。
- **`chrome-extensions`（副包）**：27 KB `SKILL.md` + 23 份 Chrome Manifest V3 扩展开发文档（Service Worker、Content Script、Side Panel 等）。

#### 2. 底层运行原理（本地离线混合检索，零 API Key）
它不是把 211 份文档全塞进上下文，而是做了一套**本地零依赖 CLI RAG**：
1. 写前端代码前，Agent 按“2–5 词英文动作查询”调 CLI：`modern-web-guidance search "light dismiss dialog"`；
2. CLI 在本地用**内置零依赖语义嵌入模型 + BM25 搜索引擎**离线匹配（不调外部搜索 API），只返回精简的 `[{id, description}]` 列表；
3. Agent 挑中条目再调 `retrieve "<id>"`，只把命中的 1–2 份指南注入上下文；同时对实验性 Origin Trial / 单引擎不稳定 API 设有 `.mwgrc` 门禁，防 AI 盲用不稳定特性；
4. 附带一个 `legacy-scan <path>` 静态扫描命令（覆盖约 20% 指南），专门用来扫老代码里的过时写法。

4. **和本机 Electron Sidecar / `generative_ui` 主题契约打架**：

### 1. `DuarteSantos8/openGym`：原理与对健身的实际帮助

#### 它是什么、底层怎么运作（[实测] `README.md`）
