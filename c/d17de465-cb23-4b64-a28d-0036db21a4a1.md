```
你提问 ──► 主模型（Gemini / Codex，花你的主力额度）
              │  ① 先看一眼“路由规则”（决定要不要叫外脑、叫哪个模式）

              ▼  （若两份报告合起来超字数、或需要交叉核对）

              │  把两人的报告去重合并、驳回瞎猜，压成精炼干货

         回传给主模型 ──► 主模型做最终裁决并按你的习惯讲给你听
```
