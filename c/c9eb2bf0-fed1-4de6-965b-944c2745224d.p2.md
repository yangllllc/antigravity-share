### [T5/12] Antigravity Assistant
这些词能串成一条线，我判断课题组做的是**DBR 微腔里的激子极化激元**（这是根据词汇推断的，未验证，可以找师姐确认一下）。

## 1. 名词速通

| 词 | 物理图像 | 和课题的关系 |
|---|---|---|
| **DBR** | 分布式布拉格反射镜：两种折射率的材料交替堆叠，每层光学厚度 λ/4，各界面的反射同相叠加，在一个波长带（"阻带"）内反射率可以超过 99.9% | 两块 DBR 相对放置就构成微腔 |
| **高 Q 值** | Q = λ/Δλ ≈ 光在腔里存活的周期数。Q 越高，谱线越窄，光子寿命越长 | 光子寿命长，才来得及和物质发生强相互作用 |
| **局域场** | 光场被压缩在很小的体积里，局部场强被放大 | 场越强，光和物质耦合越强；Purcell 因子正比于 Q/V |
| **激子** | 半导体中电子和空穴靠库仑力束缚成的"类氢原子"，是一种玻色子 | 提供"物质"部分 |
| **激子极化激元** | 腔光子和激子强耦合后形成的半光半物质准粒子，谱上表现为上下两支能带分裂（Rabi 分裂） | 课题主角 |
| **BEC（玻色-爱因斯坦凝聚）** | 大量玻色子占据同一个最低量子态 | 极化激元质量极小，室温附近也可能凝聚，凝聚后发出相干光 |
| **哈密顿量** | 描述系统能量的算符，它的本征值就是能带 | 最简单的是 2×2 矩阵：对角元是光子能量和激子能量，非对角元是耦合强度 g |
| **非厄米哈密顿量** | 把损耗（虚部 −iγ）写进对角元，本征值变成复数 | 腔会漏光、激子会衰减。这类系统有"奇异点（EP）"等新物理 |
| **摩尔转角** | 应为 **moiré twist angle**（莫尔/摩尔转角）。两层周期结构扭一个小角 θ，叠出周期大得多的莫尔超晶格，周期 ≈ a/θ | 用转角来调控激子或光子的能带，是当前的热点方向 |

**判断激光产生的条件**（组会上常用的三个判据，要同时满足）：
1. 输出强度对泵浦功率的曲线出现**阈值拐点**（双对数坐标下呈 S 形）；
2. 过阈值后**线宽突然变窄**；
3. 出现**相干性**：用干涉测一阶相干 g⁽¹⁾，或用 HBT 测 g⁽²⁾→1。

极化激元凝聚和普通激光的区别在于：前者不需要粒子数反转，阈值更低，而且能量随密度会发生**蓝移**。

## 2. NA = 0.7 → θ = 44.4° 是怎么回事

$$\sin\theta_{max} = NA = 0.7 \;\Rightarrow\; \theta_{max} = \arcsin 0.7 = 44.4^\circ$$

这是**角分辨光谱（傅里叶成像）**：物镜后焦面上的每个点对应一个出射角，所以图上的横轴是角度，也就是面内波矢

$$k_\parallel = \frac{2\pi}{\lambda}\sin\theta$$

你看到的 631–690 nm 的图应该就是**色散图**（波长对角度）。物镜能收集到的最大角度由 NA 决定，色散曲线在图上的截止边缘就对应 44.4°。老师的思路是**反过来用**：从截止处的波长和 k 读出实际的 sinθ_max，也就是实际 NA，再和标称值 0.7 对照，以此检验光路有没有用满 NA。
