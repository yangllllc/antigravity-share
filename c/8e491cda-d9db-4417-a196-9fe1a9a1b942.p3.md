#### 核心设计：**头部状态三明治摘要（硬封顶 ≤ 3,200 字符）+ 倒序全量无损归档**

1. **安全预算与三段式置顶摘要（`Build-AgentMarkdown`）**
   为约 4,000 字符上限预留 ~20% 安全裕度（硬控制在 `3,200` 字符以内），确保外部 AI 只抓取前 4,000 字符时也能同时拿到“初始目标 + 最新指令 + 最终断点结论”：
   - **极简元信息头（`≤ 180` 字符）**：标题、`conv_id`、总轮次、更新时间与倒序阅读提示。
   - **`[ANCHOR T1 / 初始目标]`（`≤ 300` 字符，头部截断）**：锚定第 1 轮 User 原始需求。
   - **`[LATEST USER / 最新指令]`（`≤ 300` 字符，头部截断）**：锚定最后 1 轮 User 指令（若全会话仅 1 轮则跳过避免重复）。
   - **`[LATEST BREAKPOINT / 最新断点尾部]`（`≤ 1,600` 字符，尾部优先保留）**：提取最后 1 轮 Assistant 回复，先通过线性状态机将 ` ```...``` ` 代码块折叠为 `[CODE: N chars]` 并压缩多余空行，再**从尾部截取最新 `≤ 1,600` 字符**，确保收尾结论与断点状态必然命中前 2,500 字符窗口。
   - **`[USER TIMELINE / 历史指令脉络]`（仅当轮次 > 4 时追加，总预算 `≤ 500` 字符）**：用单行微缩摘要（每条 `≤ 80` 字符）列出关键 User 轮次走势，绝不挤占上述核心段落。
2. **倒序全量无损正文（`## Full Transcript (Reverse: Latest -> Earliest)`）**
   - 紧接置顶摘要之后，按 `Turn N -> Turn 1` 倒序输出全部已脱敏的完整轮次正文（紧凑标题如 `### [T14/14] assistant`），零 HTML 标签、零 `<aside>`。
   - 这样前 4,000 字符既能装下完整摘要与最新几轮正文，又能让不截断的客户端无损读取全量历史。
3. **PowerShell 5.1 工程加固细节**
   - **UTF-16 代理对安全截断**：新增 `Safe-TruncateHead` / `Safe-TruncateTail`，在截断边界检查 `[char]::IsHighSurrogate` / `IsLowSurrogate`，防止切碎 Emoji（如 `🪐`）产生乱码字符。
   - **无回溯代码折叠**：`Compress-ForSummary` 采用逐行扫描状态机折叠代码块，禁用跨行 `(?s).*?` 正则，保障 `hooks.json` 的 `25` 秒超时安全。
   - **内容比对防抖写入**：使用脚本现有的 `$utf8NoBom`（UTF-8 无 BOM）与 LF 换行构建 `.md` 文本；若目标 `site\c\<id>.md` 已存在且内容完全一致，跳过写入，避免产生无意义磁盘 I/O 与 Git 噪声。
   - 现有 `git add -A` 会自动跟踪提交 `site\c\<id>.md`，同步后即可通过 `https://yangllllc.github.io/antigravity-share/c/<id>.md` 访问。
