Antigravity Assistant

先把两个关键现象说清楚：你没有看漏，也无法在不改 Antigravity 软件主程序的前提下，把第三方插件硬塞进 Settings 菜单或左侧主栏成为独立一级按钮。但你已经可以通过对话按钮、Customizations（插件中心）或对话右侧面板直接打开完整中文界面。

一、为什么会这样？（实查结论）

  • 为什么左侧主栏和 Settings 里没有单独多出这个插件按钮
  • 核查 Antigravity 主程序前端逻辑与运行时开关（GetMendelFlags）：左侧主栏插件独立分区（x2c / pluginSidebarSection）当前被特性开关 enable-plugin-sidebar-section 关闭；Settings 菜单项也是内置硬编码列表（Account / General / Appearance / Notifications / Customizations / Browser / App / Shortcuts / Models / Developer / Running）。
  • 第三方插件只能挂载到 Antigravity 开放的两个原生位置：Customizations（插件中心） 与 对话右侧辅助面板（Extensions / Aux Pane）。
  • 为什么观察一圈发现“多了两个项目”
  • Antigravity 的语言服务会自动为带 Web UI 服务的插件创建一个后台沙盒载体项目。目前你的本地项目共有 4 个非临时项目 ID：
  • 你的真实业务项目：Zemax（已恢复到首位）和 光路；
  • 插件服务载体项目：antigravity-archive-manager/archive_manager（我们刚创建的归档管理后台服务）和 swarm/swarm_board（Antigravity 内置多智能体扩展自带的后台服务）。
  • 主界面左侧栏会隐藏这类带 sidecar 标记的服务载体，但 Settings 设置页左侧的 Projects 列表（YRb）没有过滤掉它们，所以你会同时看到它们。不要手动删除这两个带 / 名称的项目（插件面板里的“项目列表”已自动隔离它们，不会让你误删）。
