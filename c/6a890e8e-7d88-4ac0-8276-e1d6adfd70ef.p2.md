### 核心矛盾与暂缓直接覆盖的原因

**核心矛盾**：你当前正在靠 `1.6.2` 联网，但 `1.6.2`（Electron / NSIS）与 `2.4.6`（Inno Setup）属于**跨代不同安装框架**——直接覆盖会留下旧版垃圾与服务冲突，而卸载旧版会立刻中断外网（含当前会话与模型的连接）。

动手前定位到 3 个必须规避的失效机制：
1. **不能直接硬覆盖**：Inno Setup 安装器无法自动卸载旧版 NSIS（卸载 GUID 不同），直接覆写进 `D:\sakuracat` 会导致 414 MB 的旧版 Electron/Chromium 文件、`Uninstall SakuraCat.exe` 及后台服务 `com.vortex.helper` 全部残留，并产生两个卸载项与潜在代理/TUN 冲突。
2. **不能直接强杀进程**：当前系统代理 `HKCU\...\Internet Settings\ProxyEnable = 1`（`127.0.0.1:7897`）。若强杀 `SakuraCat.exe` 而不清除系统代理，连国内直连及新版 `2.4.6` 登录接口都会无法访问（官网教程也专门提醒了这一点）。
3. **装完无法自动恢复联网**：官网教程明确说明 `2.4.6` 安装后需用注册邮箱/密码重新登录，并手动开启主页的 **系统代理** 开关才会恢复联网（首次启动还会弹出 Windows 防火墙授权提示，需点“允许”）。

### 请确认执行方式（选其一）

- **方案 A（推荐，全自动本地迁移，断网瞬间不影响本地安装脚本跑完）**：
  确认后我直接通过一条本地 PowerShell 流程按序完成：
  1. 备份旧版用户目录 `C:\Users\Administrator\AppData\Roaming\sakuracat`；
  2. 停止 `SakuraCat.exe` 并将 Windows `ProxyEnable` 重置为 `0`（防止断网锁死）；
  3. 静默卸载旧版 `"D:\sakuracat\Uninstall SakuraCat.exe" /allusers /S`，清理 `D:\sakuracat` 残留文件并检查停止旧服务 `com.vortex.helper`；
  4. 以 Inno Setup 参数 `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART /DIR="D:\sakuracat"` 干净安装 **`2.4.6`** 到 `D:\sakuracat`；
  5. 校验新版本并**自动拉起 `SakuraCat 2.4.6` 窗口**。
  > *注意*：执行第 2 步起本对话会暂时掉线，等你看到弹出的 `2.4.6` 窗口后登录并开启**系统代理**，网络和对话即会恢复。

- **方案 B（完全手动可控，零对话中途卡死风险）**：
  1. 你先右键右下角托盘图标点击**“退出”**关闭 `1.6.2`（自动解除系统代理），再运行 `Uninstall SakuraCat.exe` 卸载旧版；
  2. 双击我已下好的 `com.sakuracat.app-2.4.6-windows-setup.exe`（若弹 SmartScreen 点“更多信息 → 仍要运行”），安装路径选 `D:\sakuracat`；
  3. 登录并开启**系统代理**恢复联网后告诉我，我再帮你复查 `D:\sakuracat` 版本号及 `com.vortex.helper` 是否有残留。
