### 一、 全面诊断：5 项不足与改进原理

#### 1. 【本次已修】`.md` 纯净版的本地路径冗余、半行截断、重复指令与连续回复漏段
- **问题实测**：检查最长样本 `c0f340d4-8f08-43e4-a09b-e83d54aabc7e.md`（原 `45,240` 字符，15 轮）发现 4 个缺陷：
  1. 正文混入大量 ``文件名`` 绝对路径，既暴露本机目录，又白白吃掉上万字符配额；
  2. `Safe-TruncateTail` 按固定字符数硬切，把 Markdown 表格从中间劈断（出现 `....4.0 | 已全端升级...`）；
  3. `[USER TIMELINE]` 未去重，相邻重复指令（`T7`、`T8`）占用两条配额；
  4. 同一轮任务触发工具/重启后产生连续多条 `PLANNER_RESPONSE`（如 `T13~T15`），原逻辑只取最后一条 `T15`，会漏掉前序分段结论。
- **改进原理**：
  - 增加 `Strip-LocalFileLinks`，将 ``label`` 清洗为 `` `label` ``；
  - `Safe-TruncateHead` / `Safe-TruncateTail` 在靠近切割点 28%~30% 范围内优先对齐到 `\n` 换行边界；
  - `[USER TIMELINE]` 相邻去重；`Latest Breakpoint Tail` 自动聚合最后一个 User 之后的所有连续 Assistant 分段（标记为 `T13-T15`）。

#### 2. 【本次已修】无变更空跑重写、吞错、并发竞争与代码高亮冲突
- **问题实测**：
  1. 原脚本用每秒变化的 `Get-Date` 填充 HTML 的 `{{SYNC_TIME}}`，且未对 HTML 使用 `Write-TextIfChanged`，哪怕没有新对话变化，再次运行也会导致全部 HTML 变脏并触发空内容提交；
  2. 全局 `$ErrorActionPreference = "SilentlyContinue"` 吞掉 JSON/IO 异常；`$turns +=` 随轮次增长做数组拷贝；两个窗口同时结束会竞争 `site\.git\index.lock`；
  3. `Format-Inline` 先替换 `` `code` `` 再匹配 `**bold**`，会把代码中的 `**kwargs` 错染成 `<strong>`；`Redact-Secrets` 缺少私钥块与 `xox*` / `npm_` / `AKIA` 等密钥模式。
- **改进原理**：
  - 用最新会话的 `update_time` 填充页面 `{{SYNC_TIME}}`（仅在 `git commit` 说明保留精确执行时间），并对所有 `.html` 统一走 `Write-TextIfChanged`，**无对话变更时做到 0 磁盘写入、0 空提交**；
  - 引入 Windows 命名互斥锁 `Local\AntigravityShareHubSync`（等待 5s）串行化并发 `Stop` Hook；改用 `List[object]` 存轮次并记录 JSON 解析异常到 `sync.log`；
  - `Format-Inline` 先用私有区占位符保护行内代码再解析加粗与外链；扩充 `Redact-Secrets`（私钥块匹配前先用 `IndexOf("-----BEGIN ")` 短路，零常规性能损耗）。

#### 3. 【待您确认下一步】内联 `<aside>` 侧边栏引发的“改 1 个会话，脏全部 N 个 HTML”写放大
- **实测证据**：查看最新自动同步提交 `9dcbc94` 的 diff：当时**只有 `e6d7cdfe` 1 个会话更新**，但仓库里**全部 12 个历史 `.html` + `index.html` 全被改写提交**（每个历史 HTML 改 `6 +-`）。
- **底层原理**：每个 `c/<id>.html` 都把完整侧边栏 `{{SIDEBAR_ITEMS}}` 内联写死在页面里。任意会话新增或更新，都会连带修改其余全部 N 个历史 HTML。会话增多到上百个后，每次推送都要重写并失效全部页面 CDN 缓存，且大幅拉长 `Stop` Hook 耗时。
- **改进方向（需联动修改 `template.html` + `sync_share.ps1`）**：将 `<nav class="conv-list">` 抽离为全站共享的 `site/sidebar.js`（各页面仅引入 `<script src="../sidebar.js"></script>` 渲染双栏）。改动后，**更新 1 个会话仅修改 3 个文件**（对应 `.html`、`.md` 与 `sidebar.js`），历史 HTML 零 diff，且不执行 JS 的云端抓取器即使访问 `.html` 也不会看到任何侧边栏噪音。

#### 4. 【待您确认下一步】网页 UI 缺少 `.md` 纯净版直达 / 一键复制按钮
- **实测证据**：`template.html` 顶栏只有 `复制当前分享链接`（复制 `window.location.href` 即 `.html` 链接，在首页 `index.html` 点复制甚至拿不到具体会话的直链）。
