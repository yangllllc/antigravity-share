## 讲解：你问的三个"为什么"

### 1. 为什么是 M1 对 I1、M2 对 I2（一句话版本）

把光束的任何变化拆成两部分：**在 M2 上落点的位置**，和**离开 M2 时的方向**。

| | 改变 M2 上的落点 | 改变出射方向 |
|---|---|---|
| 转 M1（δ） | **2δL（很大）** | 2δ |
| 转 M2（θ） | **0** | 2θ |

| | 读到的主要是 |
|---|---|
| I1（离 M2 只有 d1，很近） | ≈ **M2 上落点的位置**（方向误差只乘上很短的 d1） |
| I2（离 M2 有 d2，很远） | **方向**（方向误差乘上很长的 d2） |

所以 **M1 管位置，用 I1 看；M2 管方向，用 I2 看**。I1 就是那个"看不见的点"的替身。这和你第一次的几何图像完全一致：M1 负责把光打到 M2 上的固定点，M2 负责把方向摆正。

用默认参数（L = 50 cm，d1 = 10 cm，d2 = 60 cm）算：
- 正确配对时，每轮误差变为原来的 r = (d1/d2)·(L+d2)/(L+d1) ≈ **0.31 倍**，越调越小。
- 反向配对时，每轮误差变为原来的 1/r ≈ **3.3 倍**，越调越大。

### 2. 欠填充为什么焦斑变大：衍射的物理机制

**最简单的模型**：两束平面波分别以 +θ 和 −θ 的角度相交，会形成干涉条纹，条纹周期是 λ / (2 sin θ)。焦点可以看成后孔径里每一个点发出的平面波，从各个角度汇聚过来叠加的结果。**能形成的最细结构，由角度最大的那两束光决定**，也就是来自孔径最边缘的光。这就是阿贝公式 d ≈ λ / (2NA) 的来源。

**欠填充**时，孔径边缘没有光，最大角度 θ 变小，能形成的最细结构变粗，焦斑就变大。

**等价的说法**：物镜把后孔径上的光场做了一次**傅里叶变换**，变到焦面上。孔径里的光越窄，焦斑越宽，这和单缝衍射"缝越窄，衍射斑越宽"是同一个道理。用高斯光束写出来就是：

$$w_0 \approx \frac{\lambda f}{\pi\, w_{\text{in}}}$$

其中 w_in 是入射光束半径，w0 是焦斑半径。入射光束细 3 倍，焦斑就粗 3 倍。

### 3. 球差，以及它的物理模型

- **球差是什么**：球面透镜对**离光轴远的光线**（边缘光）折射得过强，所以边缘光和靠近光轴的光聚焦在光轴上**不同的位置**，焦点被拉成一段，变模糊，峰值光强下降。
- **物镜为什么对输入光有要求**：物镜由多片透镜组成，设计时让各片透镜产生的球差**互相抵消**。但这种抵消只在**一种特定的使用条件**下成立：平行光输入、0.17 mm 厚的盖玻片、指定的浸没介质。输入光一旦变成发散光，光线在每片透镜上的高度和角度都会变，原来的抵消就被破坏，剩下的球差就会冒出来。
- 所以输入发散光有两个后果：①焦点偏移；②残余球差导致焦斑变大变形。

### 4. 为什么在 I1 叶片上观察回射光

返回的光会从 I2 那一侧往回打到 I1 上。把 I1 关小，就能在它**朝向 I2 的那一面**（也就是背向激光器的那一面）看到返回的光点。这样做有三个原因：
- **安全**：光不会射进激光器，也不会射进眼睛。而且装了隔离器也不影响观察。
- **有基准**：I1 的中心本来就在光轴上。返回光点套在小孔正中间，就说明元件是垂直的。
- **灵敏**：被检查的元件到 I1 距离最长。元件倾斜 α，返回光点就偏移 2α × 距离，距离越长偏移越明显。

这三点在**水平和竖直两个方向上**同时适用，和"同一高度"不是一回事。
