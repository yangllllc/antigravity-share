### 一、`deepseek-stack` 真正值得我们学的 5 个思路（精炼提炼）

这个仓库名义上是给 DeepSeek 当拐杖，但剥离掉 7 个团队 GitHub PR 流水线技能和已被我们覆盖的部分（如 `ds-jury` 已被同济双核 MCP 覆盖、`ds-unslop` 已有更强的中文 `lieflat-less-ai-tone`、`ds-swarm` 已有原生 `swarm`）后，它有 **5 个元设计对强主力模型同样极具杀伤力**：

1. **双次失败即停的前提爆破（`ds-unstick`）**：同一个报错修了两次还复现，**禁止做第 3 次微调**。必须停手写出前两次共享的隐含前提（比如“我改的这个文件真的在运行吗”“环境变量真的生效了吗”），用最便宜的探针做 Yes/No 实测证伪，必要时 `git checkout/stash` 清现场换机制。强模型在环境坑、缓存坑里一样会钻牛角尖，这是全库最值钱的机制。
2. **外部真值 5 级举证阶梯（`ds-blast-radius` + `ds-mode`）**：把“我觉得没问题”拆成 L1 口述 → L2 指明 `file:line` → L3 路径推演 → L4 写小脚本运行反证 → L5 实机复现，并要求结论显式区分 `measured / inferred / guessed`。
3. **不缺额度时的终极增效器——盲评与局部嫁接（`ds-best-of-n`）**：对高价值任务（关键算法、复杂重构、重要 UI），用隐藏评分细则跑 3–5 个隔离工作区（Antigravity 原生支持 `swarm(workspace:"share", n:3)`），先运行淘汰不能跑的，选架构最好的作底座，**只把其余方案里的单个亮点函数或边界测试局部嫁接进来**，绝不整文件合并。你既然不缺额度，这是把算力直接兑换为质量上限的最稳方法。
4. **把确定性轮询封装为黑盒脚本 + 退出码（`ds-watch-pr`）**：全库唯一带脚本的技能，用 `watch_pr.py` 输出精简变化行与 `0/1/2` 退出码，不让 LLM 自己写循环、读大段原始 JSON 污染上下文。
5. **反规则膨胀的五级硬固化（`ds-lessons`）**：核心理念 *"An instruction an agent can skip is a wish"*——重复 ≥2 次的错误按 **架构结构 > 类型约束 > Lint/CI/Hook > 行为测试 > 文字规则** 固化，且**一旦硬约束生效，删掉对应的自然语言规则**。这恰恰和我们接下来要讨论的“规则/记忆膨胀”形成正面呼应。

### 二、先补齐底层知识：Skill 到底是怎么运行的？为什么装了经常没用到？

结合 Antigravity 官方文档（`skills.md`、`rules.md`、`hooks.md`、`customization-discovery.md`）与你本机的实测配置，Agent 定制系统实际上是**四层完全不同的加载机制**：

| 机制 | 启动/每轮默认注入什么？ | 何时生效？ | 触发可靠性 |
| :--- | :--- | :--- | :--- |
| **Rules (`always_on`)** | **全文直接注入系统提示词**（单文件上限 24 KB，总预算 20,000 token，超额自动把最大文件降级成路径指针） | 每一轮都强制在场 | 最高（但在规则过多时会出现中段注意力稀释） |
| **Rules (`glob` / `model_decision` / `manual`)** | `glob` 按文件后缀匹配注入；`model_decision` 只注入路径+一句话描述；`manual` 仅在用户 `@` 提及时注入 | 匹配路径 / 模型自己觉得该读 / 用户显式 `@` | `glob`、`manual` 高；`model_decision` 低 |
| **Skills (`SKILL.md`)** | **只注入 `name` + `description` + 文件路径**（即渐进式披露 Progressive Disclosure），**正文和脚本默认完全不加载** | 两种入口：① 模型扫一眼 `<skills>` 列表自己决定调 `read_file`；② 用户手动输入 `/skill-name` | **自动触发本质等同于 `model_decision`（偏低）**；手动 `/skill-name` 为 100% |
| **Dream 分层记忆** | Tier 1 索引表通过 `always_on` 规则常驻（≤140 行）；Tier 2 `topics/*.md` 按需 `read_file` | 遇索引命中领域时按需读取 | 中高（因为索引表极短、条目清晰） |
| **Hooks (`hooks.json`)** | 不占系统提示词；由宿主在 `SessionStart` / `PreToolUse` / `PostToolUse` / `PreInvocation` / `PostInvocation` / `Stop` **强制跑外部脚本** | 宿主生命周期节点确定性拦截/注入/阻止提前停止 | **100% 确定性（绕过模型自觉）** |
