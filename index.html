1. Interface language (menus, buttons, settings)

Antigravity IDE is built on VS Code, so you change the language the same way:

  • Press Ctrl+Shift+X to open Extensions.
  • Search for Chinese (Simplified) Language Pack and click Install. Use Chinese (Traditional) if you want that instead.
  • Press Ctrl+Shift+P and run Configure Display Language.
  • Choose 中文(简体) / zh-cn, then click Restart.
[!NOTE]
The language pack only translates the parts that come from VS Code. Antigravity's own panels, such as the Agent Manager, may still show some English. I couldn't find an official Antigravity language setting in the docs I have. Check https://antigravity.google/docs or the changelog to see if one has been added.

2. NA = 0.7 → θ = 44.4° 这段在算什么

这很可能是角分辨光谱（傅里叶成像）：物镜收集不同角度出射的光，每个角度对应一个面内波矢 k∥，于是可以画出腔模的色散曲线。

  • 物镜能收到的最大角度：sin θ_max = NA = 0.7，所以 θ_max = arcsin 0.7 ≈ 44.4°。老师算的这一步就是这个。
  • 腔光子的色散关系近似为

$$\lambda(\theta) = \lambda_0\sqrt{1-\frac{\sin^2\theta}{n_{\text{eff}}^2}}$$

角度越大，波长越短（蓝移）。所以 690 nm 是 θ = 0 处的腔模，631 nm 是物镜能收到的最大角度处的腔模。

  • 反过来求实际 NA：

$$\text{NA}_{\text{实际}} = \sin\theta_{\max} = n_{\text{eff}}\sqrt{1-\left(\frac{631}{690}\right)^2} = 0.405\,n_{\text{eff}}$$

  • 我验算了一下：要和 NA = 0.7 吻合，需要 n_eff ≈ 1.73，这对微腔来说是合理的数值。所以老师和师姐争的关键，很可能是 n_eff 到底取多少。n_eff 由腔层材料和 DBR 的穿透深度决定，可以用 θ = 0 附近色散曲线的曲率（等效光子质量）拟合出来。如果算出来的 NA 小于 0.7，说明

1. 名词速查

| 词 | 物理图像 |

|---|---|

| DBR | 高、低折射率薄膜交替堆叠，每层光学厚度 λ/4，各界面反射同相叠加，在阻带内反射率可超过 99.9%。两块 DBR 夹一层材料就是微腔。 |

激射怎么判断，实验上至少看这几点：

  • 输出强度随泵浦功率出现阈值拐点（S 形曲线）。
  • 过阈值后线宽骤然变窄。
  • 出现相干性（干涉条纹，g⁽²⁾ 趋近 1）。

只看到"变亮"不能证明激射。

2. NA = 0.7 与 θ = 44.4° 这段在算什么

这很可能是角分辨光谱（傅里叶成像）：物镜把不同出射角的光收进来，每个角度对应一个面内波矢 k∥，由此画出腔模的色散。

  • 物镜能收的最大角：sin θ_max = NA = 0.7，所以 θ_max = arcsin 0.7 ≈ 44.4°。
  • 腔光子的色散近似为

$$\lambda(\theta)=\lambda_0\sqrt{1-\frac{\sin^2\theta}{n_{\rm eff}^2}}$$

角度越大，波长越短。所以 690 nm 对应 θ = 0，631 nm 对应物镜能收到的最大角。

  • 反过来求实际 NA：

$$\mathrm{NA}=n_{\rm eff}\sqrt{1-(631/690)^2}=0.405\,n_{\rm eff}$$

  • 我验算了：要让 NA = 0.7，需要 n_eff ≈ 1.73。这对微腔是合理的数。

所以老师要的"从波长反推 NA"，关键是 n_eff 取多少。n_eff 可以用 θ = 0 附近色散曲线的曲率（等效光子质量）拟合，不能随手设。这个解读是我的推测，需要对照原图确认。

3. 消色差光路

问题：玻璃折射率随波长变化（色散），不同波长焦点不重合，宽谱或超快脉冲的成像会模糊。

解法：

  • 消色差双胶合透镜：冕牌玻璃正透镜加火石玻璃负透镜，条件是

$$\frac{\phi_1}{V_1}+\frac{\phi_2}{V_2}=0,\qquad \phi_1+\phi_2=\phi\neq 0$$

φ 是光焦度，V 是阿贝数（越大色散越小）。这样两个波长焦点重合，整体仍有聚焦能力。

  • 复消色差（APO）：三个波长的焦点重合。
  • 反射式物镜或离轴抛物面镜：反射角和波长无关，原理上没有色差，代价是调节难。

4. 玻色-爱因斯坦凝聚与激子极化激元

  • 玻色子足够多、足够冷时，大量粒子进入同一个最低能态，表现出宏观相干性。
  • 腔光子与激子强耦合形成激子极化激元。它的有效质量只有电子质量的 10⁻⁴～10⁻⁵ 量级，所以在远高于原子气体的温度下就能凝聚，二维材料体系甚至可能到室温。
  • 极化激元激射不要求粒子数反转，靠玻色受激散射。所以阈值低，并且常伴随蓝移（激子之间相互作用导致）。这是区分"极化激元激射"和"普通光子激射"的重要线索。

5. 哈密顿量与非厄米哈密顿量

哈密顿量 H 描述系统能量，本征值就是能级。耦合腔光子 (E_c) 和激子 (E_x) 的最小模型是

$$H=\begin{pmatrix}E_c-i\gamma_c/2 & g\\ g & E_x-i\gamma_x/2\end{pmatrix}$$

  • g 是耦合强度，γ 是损耗（腔漏光、激子衰减）。
  • 有损耗或增益时 H 不再厄米，本征值变成复数：实部是能量，虚部对应线宽（寿命）。
  • 强耦合的判据大致是 g 大于两者线宽的差，此时出现反交叉，分裂成上、下两支极化激元。
  • 当参数调到某个点，两个本征值和本征态同时合并，叫奇异点（exceptional point），是非厄米物理的核心现象。

6. 摩尔转角（moiré，法语"莫尔纹"）

图像：两层周期结构叠在一起，转一个小角度或晶格常数略不同，就出现一个更大尺度的周期花纹，这就是摩尔超晶格。

  • 同种晶格转角 θ 时，摩尔周期

$$L=\frac{a}{2\sin(\theta/2)}\approx\frac{a}{\theta}$$

a 是晶格常数。角度越小，周期越大。

  • 在二维材料里，这个大周期势场会重塑能带，出现平带。最有名的是转角石墨烯在约 1.1°的"魔角"出现平带和超导。
  • 在 MoSe₂/WSe₂ 这类异质结里，摩尔势会把激子囚禁成规则的"人造原子"阵列，叫摩尔激子。
  • 光子体系也可以做：转角光子晶体、转角光栅，同样产生平带和光的局域，被用来做低阈值激光。

给老师交差的学习顺序：

  • 先把 L = a/(2 sin(θ/2)) 画图理解。
  • 再看"平带为什么意味着有效质量大、容易局域"。
  • 最后读一篇综述，比如搜 *moiré excitons* 和 *moiré photonic crystal laser*。
